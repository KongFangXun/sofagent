# cordis-plugin-sofagent-fde

FDE 进场方法论桥接——本体数据视图生成（fde_* 六 tool 已交付）（seam: non-seam:tool-set）

## 用途

**装上之后**：FDE 进场六工具（访谈 / 分类 / 量化 / 派生 / 蒸馏 / 部署）在宿主内可用——把「该不该上 AI、上在哪、值多少钱」的判断做成可调用的流程，而不是写死在你脑子里。无生命周期时机（工具按需调用）；桥接 `@sofagent/ontology`。

本插件随 sofagent 主线版本发布（SkillHub 通道：`skillhub install cordis-plugin-sofagent-fde` 安装与检索；npm 通道未开通）。版本号与 sofagent 主线对齐。
