# evolution · release-gate-loop 循环级演化

> **人类门控的"加一减一"改进记录。** 防止 specs / prompts 无限膨胀成屎山。

## 规则

- 每次完整循环（一个 run）结束后，若发现这套循环定义本身该变，提出**一条加 + 一条减**的建议。
- 加，specs / prompts / loop.md 该新增什么（如一个新检查维度、一个更严的覆盖规则）。
- 减：同时该删掉什么（如一个已无用的 prompt 段、一个过时的检查项）。**加而不减 = 膨胀**。
- 所有改动**必须人类确认**后才落地到文件。本文件只记录提案与结论。

## 提案模板

```
## YYYY-MM-DD run-NN
- 加：[具体改什么 / 为什么]
- 减：[具体删什么 / 为什么]
- 状态：待确认 | 已采纳 | 已否决
- 结论：(人类确认后填)
```
