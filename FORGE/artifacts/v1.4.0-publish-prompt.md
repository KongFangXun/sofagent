## 步骤二：发布前检查

```bash
bash tools/release/pre-push-check.sh        # 推前预检
bash tools/check/check-docs.sh              # 文档预算 + 死链 + Skill 行数
bash tools/check/check-test-count.sh --quiet # 测试数文档同步门禁
shellcheck engine/scripts/*.sh tools/*.sh install.sh
npm test && npm run build
# daemon CI 模拟（对齐 daemon-macos-ci.yml）
rm -rf .sofagent && mkdir -p .sofagent
SOFAGENT_DATA="${PWD}/.sofagent" engine/scripts/daemon.sh --foreground > .sofagent/daemon-stdout.log 2>&1 &
DAEMON_PID=$!; sleep 35; kill $DAEMON_PID 2>/dev/null
[ -f .sofagent/daemon.json ] && echo "✅ daemon CI 模拟通过" || { echo "❌ daemon.json 未生成"; tail -6 .sofagent/daemon-stdout.log; }
rm -rf .sofagent
# npm 包洁净度（.js.map 泄露 / tsc / README 非空）——13 包含 load-chain
```

## 步骤六：git tag + push tag

```bash
bash tools/check/check-version.sh && bash tools/check/check-test-count.sh --quiet  # tag 前最后门禁
git tag -a v1.4.0 -m "v1.4.0 · 📊 企业 AI 工作记录视图 + 🔌 约束层外化双生态插件家族"
git push origin v1.4.0
# tag 后零 commit 校验：git rev-parse v1.4.0^{commit} = git rev-parse HEAD
```
