# 红队用例集（透明仓 · 敌手自测）

> **透明仓正式入口之一**：本目录是「敌手自测」（自己打自己）的用例集与 run 结论落点。
> 与 `../anti-cases/`（他证素材）同属一条证据链——**没被打穿也要有记录**，否则等于没测。
>
> 形态归属：`[主干]` 判定·审计面红队验证｜合流方向：自探索方向迁入。

## 为什么要做敌手自测

治理面的可信度不能只靠「正向测试全绿」。正向测试证明「功能对」，敌手自测证明
「打不穿」——两者合起来才构成「能自证」的证据。透明仓（他证）要公开的正是**这条
证据链的原始记录**（判定、误报、翻案全过程）。

## 四类攻击面（成对用例）

每条用例都带**两态**：
- **预期被拦**——该攻击是否应当被某个真实机制拦下；
- **检出证据**——若未被拦（或机制只部分覆盖），留下了什么可回溯的检出证据。

| 用例 | 攻击面 | 攻击动作 | 预期被拦 | 拦不住时的检出证据 |
|---|---|---|---|---|
| **RT-01** | 一·篡改 `history.jsonl` | 改写已签名条目字段后请求链校验 | 是 | `checkHistoryChainDetailed` 判 `tampered`（锚点/签名不符） |
| **RT-02** | 一·篡改 `history.jsonl` | 删除整份审计历史后请求链校验 | 是 | 判 `insufficient`（「无历史」= 无法验证，非「未受损」） |
| **RT-03** | 二·伪造 HMAC 链 | 用错误密钥重签整条链 | 是 | HMAC 不匹配 + 环境指纹一致 ⇒ 判 `tampered` |
| **RT-04** | 三·绕过 ToolGate | 伪造工具 ID（Symbol）执行高危工具 | 是 | ID 未注册 ⇒ `deny` + `SOFAGENT_TOOL_DENIED` |
| **RT-05** | 三·绕过 ToolGate | 高危工具未经人工批准直接执行 | 是 | 判 `human-approval` + `SOFAGENT_TOOL_PENDING_APPROVAL` |
| **RT-06** | 四·恶意插件①越权 services | 插件调用未在自身声明面内的服务 API | 否（现状：运行时不强制声明面） | services 桥 `stats` + `meta.apis` 声明面可对账（详见 run 结论） |
| **RT-07** | 四·恶意插件②事件投毒 | 向事件总线投递未登记事件 kind | 是 | publish 契约层（chain-kernel kind 门）拒落盘 |
| **RT-08** | 四·恶意插件③instinct 池毒数据 | 自证「假经验」过入池审核三道门 | 否（现状：三道具查存在性） | 血缘锚点 `buildLineageAnchor` 记录 `sourceTraceId`，可回溯审计链逐条复核 |
| **RT-09** | 四·恶意插件④apply 供应链注入 | apply 阶段挂载外写动作（挂载即改配置） | 是 | `plugin-mount-probe` 第五段安全段判 `reject`（拒载） |

> 第四类（恶意插件）是 **hub 时代**（v1.5.4 cordis 兼容层引入后）新增攻击面——
> 前三类是「篡改已落盘的证据」，第四类是「插件在桥/池/挂载点上的越权与投毒」。
> 训练毒数据（RT-08）比推理时操纵更隐蔽：结晶的「假经验」被 S1M 学走后才发作，
> 故检测须回溯到**入池审核链**（本仓落点：`engine/orchestrator/src/instinct/exporter.ts`
> 三道门 + 血缘锚点）。

## 执行器：`tools/check/red-team-runner.mjs`

跑真实机制（不是模拟打勾），对每条用例产出**两态判定**：

| 判定 | 含义 | 去路 |
|---|---|---|
| `BLOCKED` | 预期被拦且实际被拦 | 绿 |
| `DETECTED-UNBLOCKED` | 未被拦，但有检出证据 | **进 anti-cases 留证**（「没被打穿」也要有记录） |
| `PENETRATED` | 未被拦且无检出证据 | **进回归清单**（须修） |
| `BLIND` | 机制加载不到/执行异常 | 失明，拒绝把「读不到」当「已通过」 |

退出码对齐本仓 `check-*` 家族三态：**0 = 绿 / 1 = 有违规（存在穿透）/ 2 = 失明**。

```bash
node tools/check/red-team-runner.mjs          # 人读输出 + 退出码
node tools/check/red-team-runner.mjs --json   # 机器可读（含逐条两态）
```

> 机制依赖 engine 各包 `dist`（`npm run build`）。dist 缺失即失明（exit 2），不静默降级为「通过」。

## 透明仓公开面硬边界

公开面**零租户数据 / 零凭证**——只公开**治理原始记录**（判定、误报、翻案过程），
不含任何租户数据与企业凭证。核对实证见 [`../evidence.md`](../evidence.md)「误报率读数与透明仓开仓闸门」节。
