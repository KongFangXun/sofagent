## 用户反馈

> 「如果你有一个硅基员工想做电商或团队的数字化，sofagent 的 FDE 十步流程能帮你系统性地梳理什么该交给 AI、什么还留给人做——不仅仅是一个约束工具，更是一套部署方法论。」

**遇到的改进需求**：
1. 电商平台反爬严重，运营核心流程数据无法自动获取（标记为 👤，待小嘉+影刀配合突破）
2. FDE 模板默认配置带 # 注释，初次使用容易遗漏去注释
3. GitHub 直连不通，需离线安装方式（已支持但文档未突出）
