## 部署成果

### FDE 十步流程

- **§一~§二**：企业画像 + 技术环境清单（自研ERP + 用友U8 + 钉钉OA，全API可达）
- **§三**：7个部门工作流深挖，梳理 71+ 个日常节点
- **§四**：AI 节点识别——2 个 🔄 自动执行节点已确认
- **§六**：产出完整部署方案书 + workflow.yaml
- **§八**：交付物打包

### 已识别的 AI 节点

| 节点 | 部门 | 类型 |
|------|------|:--:|
| 价格与合同管控 | 财务部 | 🔄 |
| 来料验收对接 | 质检部 | 🔄 |
