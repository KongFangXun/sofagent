## 各维度测试概要

| 维度 | 测试方法 |
|------|------|
| daemon 进程检测 | `pgrep -f` 检测各平台 Agent 进程名，记录 daemon.json `detected_platforms` |
| 步数闸生效 | 给 Agent ≥50 步任务，观察是否在 MAX_STEPS 时收尾 |
| 熔断闸生效 | 触发子 Agent 连续失败 3 次，观察是否熔断跳过 |
| 幂等检查生效 | git push 后中断→重启相同 push，观察是否标记「幂等跳过」 |
| 评判器隔离 | 执行任务后观察闭环验证是否用不同模型/session |
| 加载链 L1/L2/L3 | 新建会话→简单任务→检查输出是否引用对应文件内容，重复 3 次取命中率 |

> 详细步骤见 [docs/test-cases/platform-v081.md](./test-cases/platform-v081.md)
