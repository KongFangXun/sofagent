## SubAgent Agent Mailbox（从 v1.2.5 P6b 拆入）

> 来源：v1.2.5 规划 P6b（SubAgent 间异步消息）。v1.2.5 瘦身时拆至本版，与 Session Goals / HITL 中断处理协同更自然。

**问题**：当前 SubAgent 间通信只有 `artifacts` 字段（单向、同步、全量替换）。reviewer 发现 engineer 正在写的文件有冲突无法实时通知；engineer 需要问 auditor「这条规则的具体含义」无法直接提问。

**设计**：每个 SubAgent 一个邮箱目录（`data/agent-mailbox/<agent>/inbox/`），消息以 JSON 文件投递。在 LOOP StateGraph 每个节点开始前扫描邮箱，高优先级消息注入 system prompt（非中断执行，只补充上下文）。

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/orchestrator/src/mailbox/mailbox.ts` | 新建 | 邮箱读写（send / read / markRead） |
| `engine/orchestrator/src/mailbox/message-injector.ts` | 新建 | 节点开始前扫描邮箱 → 注入 system prompt |
| `engine/orchestrator/src/mailbox/index.ts` | 新建 | 导出 + 类型 |
| `engine/orchestrator/src/loop/nodes.ts` | 修改 | 每个节点 wrapper 加邮箱检查 |
| `engine/orchestrator/src/__tests__/mailbox.test.ts` | 新建 | 发送/接收/注入全流程单测 |

> 与 L2 协作协议（v1.3.3）的关系：L2 处理「多设备/多 Agent 编排级」协作（共享态/意图广播），Agent Mailbox 处理「单个 LOOP 内 SubAgent 之间」的点对点通信。两者互补不冲突。
