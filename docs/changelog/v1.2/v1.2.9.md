## 🔗 激活链 Phase 3 后半：HITL + 审计集成 + 异常处理

### 定位

v1.2.8 让 dag-runner 能跑企业 Agent。v1.2.9 补上三个关键运行时能力：⚡ 节点暂停等人确认 + 每个节点执行后自动审计 + 异常处理。

### 交付

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/orchestrator/src/hitl-handler.ts` | 新建 | HITL 中断处理（展示方案 → 等待确认 → 继续/终止） |
| `engine/orchestrator/src/node-executor.ts` | 修改 | 新增审计集成（每节点执行后自动审计） |
| `engine/orchestrator/src/enterprise-graph.ts` | 修改 | 接入 interruptBefore |
| `engine/orchestrator/src/__tests__/hitl-handler.test.ts` | 新建 | 单测 |

### 运行时行为

```
每个 🔄 节点：自动执行，结果写入 State + entity
每个 ⚡ 节点：执行到此处暂停 → 向用户展示方案 → 等待确认 → 继续
每个节点执行后：自动触发审计
审计 FAIL：暂停整个工作流，通知用户
异常：写入 exceptions 队列，根据节点配置决定重试 or 跳过
```
