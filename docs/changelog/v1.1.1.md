### 问题 1（P1）：acceptance-test 31 场景未全量验证

**现状**：场景 1-9 PASS，场景 10 起在 git 临时仓库中偶发卡死。

**根因**：场景 10（--no-verify 绕过检测）在连续场景中创建 commit，但前序场景的 `.env` 文件残留污染了 git 状态。

**方案**：每个场景结束后增加 `git reset --hard` 清理 + `rm -f .env`。

---

### 问题 2（P1）：experience sharing 真实验证

**现状**：发布检查清单第 5 项 `[ ]`。`harness/src/index.ts` 中 `knowledge/shared/` 注入逻辑已写（C-1），但缺少：
1. 真实 think.md 数据 → lessons 提取 → shared knowledge 写入的端到端验证
2. 多设备共享流程的实证（第二台设备导入 shared knowledge 后 Agent 行为变化）

**方案**：创建最小复现用例——用测试脚本模拟"设备 A 踩坑→写 think.md→提取 lessons→设备 B 加载 shared knowledge→加载链检查注入内容"。
