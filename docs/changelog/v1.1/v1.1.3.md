# v1.1.3 开发日志 — LangGraph StateGraph + Checkpoint + HITL

> 状态：开发完成 · 待发版 · 孔放勋 · 2026-07-15
> 前置依赖：v1.1.2（测试体系修复完成，acceptance-test 55 场景覆盖）

## 背景

v1.1.2 已通过 DeepAgents compose（composeWithDeepAgents 一次性生成 YAML）实现 engineer → reviewer 自动串联。v1.1.3 的真实增量是**编排控制上提为 sofagent 直接掌握的 LangGraph StateGraph 节点级流转**——不再是 DeepAgents 一次性 compose 出整个工作流 YAML，而是每个节点是一次独立的 StateGraph step，节点间通过 State artifacts 传递上下文，支持细粒度条件路由（audit PASS/WARN/FAIL → 不同后续节点）、中途 Checkpoint 持久化与恢复、HITL 人工确认驳回回 engineer 的闭环。

## 交付一：LangGraph StateGraph 自动流转（P0）

`import @langchain/langgraph`——直接使用 StateGraph 自定义 Sub Agent 的多步骤状态流转（ROADMAP 原定 v1.1，延到此处落地）：

```
StateGraph:
  START → engineer(AI) → audit(CLI) → reviewer(AI) → human_confirm(HITL) → END
                                     ↓ FAIL
                                    engineer(AI) 
```

- **StateGraph**：定义 agent_graph，节点为 engineer / audit / reviewer / human_confirm
- **自动流转**：节点执行完毕自动触发下一个节点，不再需要人手动调 CLI
- **不对 v1.1.1 的 Agent 定义做任何改动**——只改编排层，不动业务逻辑

### SKILL.md 加载链 LUI-first 约束

Harness 加载链第 1 层 SKILL.md 新增一句设计铁律：

> 「本软件不提供图形界面。所有能力通过 MCP 协议暴露。Agent 首次连接时主动调用 `list_capabilities` 告知用户你能做什么。输出必须推送到用户面前，不要让用户来找结果。」

### SKILL.md Agent 身份感知（v1.1.3 发版前补入）

Harness 加载链第 1 层新增 Agent 身份感知指令——让 Agent 知道自己的规则框架来自 sofagent，并在关键场景中自然提及：

> - 拦截危险操作 →「sofagent 阻止了这次提交」
> - 产出通过审计 →「✅ sofagent 审计通过」
> - 不确定、主动确认 →「按 sofagent 规范，这个需要你确认」

与 v1.1.2 的三层输出签名（CLI/Webhook/MCP）互补：签名覆盖了「输出渠道的可见性」，身份感知覆盖了「Agent 自身的可见性」。纯文本注入，无需 Hook，WorkBuddy/Codex/OpenClaw/Claude Code 全平台生效。

## 交付二：Checkpoint 持久化（P0）

长任务中断后能从 Checkpoint 恢复执行状态（当前 launcher.ts 只做心跳检测，不做状态恢复）：

- 每个节点执行前后自动 snapshot StateGraph 状态
- daemon 重启后自动从最近 Checkpoint 恢复
- 人类确认节点等待不限时（人可以明天再回来看报告）

## 交付三：HITL 确认节点（P0）

审查报告产出后，daemon 弹出确认提示，人看一眼输入 y/n。不需要人主动去读审查报告——daemon 推送到你面前。

## 验收修复：审计后自动快照（P0）

OpenClaw v1.1.3 验收发现：`--timeline` / `--revert` 永远显示"暂无快照"。根因是 audit 审计主流程完成后只写 `history.jsonl`，没有调用 daemon 的 shadow repo 快照机制——`createPostAuditSnapshot` 封装层存在但从未被调用。

**修复**：在 audit `index.ts` 的 `appendHistory` 之后、`process.exit` 之前，当审计结果为 PASS 且在 git 仓库中时，调用 core 的 `createShadowRepo` + `commitSnapshot` 创建快照。绕开 audit→daemon→audit 循环依赖，直接用 core 的底层函数。

**验证**：修复后 commit 一次，`--timeline` 正确显示快照记录（1 文件），`shadow repo` 在 `.sofagent/.git-shadow/` 创建。
