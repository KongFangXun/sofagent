## 视角7：红队
- **发现1（P1）**：`gateway/proxy-gateway.ts:308` HITL checkpoint 用 `writeFileSync(tmp)` + rename 写 pending/——检查该 tmp 是否可预测路径（若 mktemp 随机则 OK）。**待取证**：读 :300-315 确认 tmp 生成方式与符号链接攻击面（攻击者在 pending/ 目录预置同名文件/symlink）。同类：`key-manager.ts:159` 密钥 tmp+rename——**密钥场景更敏感**，若 tmp 名可预测且在共享目录，symlink 竞态可劫持密钥写入（建议 mkdtemp 或 O_EXCL）。
- **发现2（P2）**：`wal-writer.ts:188` chmod 0o600 在 open 之后——文件短暂以默认 umask 存在（TOCTOU 窗口）。POSIX 惯例是 open 时带 mode（已有 0600 mode 参数的写法更稳）。WAL 含 params（可能含敏感参数），低风险但值得修。
- **发现3（P2）**：`undo-registry.ts` gitRestore 用 `execFileSync('git', [...])` 数组参数（零注入，好）；但 git 二进制路径解析走 PATH——被审计的 Agent 若能改 PATH 环境变量可让 undo 跑恶意 git。深度防御可考虑 which git 预解析。观察项（威胁模型边缘）。
