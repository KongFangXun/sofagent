## 一、SMB 场景审计扩展（数据处理/报表生成）

> **形态归属**：`[主干]`（判定·数据产物三规则）**+ `[外部]` 成分**（SMB onboarding 模板——数据类：模板 / 配方 / 规则集）｜ L1 关档
>
> 📋 **探索方向表收编**：审计从代码开发扩展到数据处理/报表生成——SMB（中小企业）没有代码仓库，但报表生成/数据清洗同样需要审计（数字对不对/来源可溯/口径一致）。

### 交付

| 组件 | 能力 |
|------|------|
| **数据产物审计规则** | 新审计维度：AI 生成报表/数据产物时审计——数值一致性（合计/明细勾稽）、来源可溯（每个数字可回溯源数据）、口径一致（同名字段同口径） |
| **DecisionKind 扩展** | 新增 DATA_PRODUCT 决策类型（data 产物审计的决策分类）⚠️ `DecisionKind` 属 **@public 契约**——新增成员须同步 `tools/check/public-api-baseline.json`，否则 API 面校验红（对照定义 `engine/audit/src/decision-schema.ts`） |
| **SMB onboarding 模板** | FDE 模板库新增 SMB 场景模板（无代码仓库的纯数据节点部署路径） |
| **治理 KPI 复用** | v1.5.0 治理 KPI 面板对 SMB 场景同样可用（审计覆盖率/问题率照常统计） |

### 涉及文件（预估）

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/audit/src/rules/data-product-rules.ts` | 新建 | 数据产物审计规则（勾稽/溯源/口径） |
| `engine/audit/src/decision-log.ts` | 修改 | DecisionKind 加 DATA_PRODUCT（既有 `decision-log.ts` 与 `decision-schema.ts` 均在 audit 包，**不在 core**；单测 `engine/audit/src/decision-log.test.ts` 同步扩） |
| `FDE/templates/smb-onboarding.md` | 新建 | SMB 场景 onboarding 模板 |
