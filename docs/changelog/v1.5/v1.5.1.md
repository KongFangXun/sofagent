## 一、进化引擎持续样本采集（≥1 周 Dream Cycle 运行）

> 📋 **探索方向表 2026-08-24 登记**：「越用越好」宣称当前仅 11 个一次性测试 Case，缺持续 ≥1 周样本与 A/B 对照。补法是跑 Dream Cycle 持续运行采集（eval passRate 曲线 + 知识库增量对照），属产品验证工作非文档修复——样本补上后收紧 README/PHILOSOPHY 措辞。候选版本：v1.4.x 后续 → 本版收编。

### 交付

| 组件 | 能力 |
|------|------|
| **持续采集管道** | Dream Cycle 连续运行 ≥7 天：每日 eval passRate 曲线 + 知识库条目增量 + 修正回流统计，落盘 `data/evolution/samples-<date>.json` |
| **A/B 对照组** | 同任务集双跑：开进化引擎 vs 关进化引擎（复用 v1.3.5 run_ab_test 基础设施），对比 passRate/修正次数/成本 |
| **样本报告生成** | `evolution report`：样本周期 + 曲线 + 对照结论 + 统计显著性——证据强度分级标注（探索方向「证据强度分级」联动） |
| **措辞收紧** | 样本达标后：README/PHILOSOPHY 的「越用越好」表述挂上实测链接（LIMITATIONS 同步更新） |
