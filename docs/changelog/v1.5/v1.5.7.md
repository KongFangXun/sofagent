## 四、能力面使用率治理（技能 SkillOps 五维 + 工具使用率遥测 · 自原 v1.5.2 后移 · 2026-09-15 / 09-16 维护者裁定）

> 🔗 **承载场景**：S475（章四·能力面治理行为锁）


> **形态归属**：`[主干]`（治理·统计与退役结论）｜ L1 关档
>
> 📋 **研究收编**（Google《Towards a Systems Foundation for Agentic Skills》arXiv:2608.29596）：技能库存储借鉴 OS 虚拟内存思想，SkillOps 提出五维技能库健康度治理——**剪除低价值技能、偿还「技能技术债」**。本仓现状：SKILL 库只进不出（instinct→skill 单向晋升），无退役机制——技能熵只增不减。综述同时实证「技能效用相当脆弱」（SkillsInWild 3.4 万技能测量）+「弱模型进化技能对强模型负迁移」（WikiSkill 4B 技能把 Gemini-3.5-Flash 从 50.5% 拉到 18.1%——v1.4.8 modelScope 门控已防）。与 [v1.5.2 第二章](./v1.5.2.md) ruleset_export / [v1.5.3 第二章](./v1.5.3.md) 自测 schema 同属「规则与技能的治理面」主题。
>
> 📋 **并入工具使用率遥测**（维护者裁定）：同一治理面从技能扩到工具——MCP 工具面目前**无调用遥测**，静态引用密度只能证明文档完备、不能证明被调用（全量盘点实测：`orchestrator/workflows`、`task/plans` 等子系统零运行时痕迹，但无法据此判断其余工具的冷热）。退役与加码决策需要真实调用数据，故补工具面使用率；**后置本版**的理由是遥测需一段数据积累期才能产出可用结论。

### 交付

| 组件 | 能力 |
|------|------|
| **五维健康度指标** | 按综述 SkillOps 框架落五维（候选：使用频率 / eval 分数趋势 / modelScope 覆盖面 / 依赖健康（引用的工具/接口是否还在）/ 年龄与版本漂移）——`skill-health report` 输出，Dashboard 可见 |
| **低价值技能退役** | 五维连续 N 期低于阈值 → 退役候选清单（进 FDE 人工确认，不自动删——对齐「只提示不阻断」）；退役技能归档不物理删（可回滚） |

| **工具使用率盘点** | `sofagent stats --tools` 输出三视图：被调用 / 零调用 / 频次分布——为工具退役与加码提供数据依据（与五维使用频率同源消费） |
| **与 evolve 门控联动** | dream-cycle 晋升面照常，本项补**出口**：晋升进来就有健康度追踪，降级/退役有据 |
