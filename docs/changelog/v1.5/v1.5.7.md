## 一、凭证隔离 Vault（OMA 启发）

> **形态归属**：`[通道]`（**执行层安全基础设施**——凭证托管/轮换/吊销是通用轮子，换 HashiCorp Vault 价值不受损；**「Agent 代码碰不到 token」的拦截约束留主干**）｜ L1 关档
>
> 📋 **探索方向表收编**：沙箱发 HTTP 请求时动态注入凭证、Agent 代码碰不到 token——执行层安全基础设施，v1.3.7 虚拟 key 凭证边界已部分覆盖，完整 Vault 前移本版。

### 交付

| 组件 | 能力 |
|------|------|
| **Vault 服务** | 凭证托管：Agent 运行时凭证不出 Vault（动态注入请求头，Agent 代码/日志/审计面均见不到 token 明文） |
| **轮换与吊销** | 凭证可轮换（定时/事件触发）+ 单凭证吊销（泄露响应） |
| **凭证范围声明（闭合审计盲区）** | Vault 侧掌握「这条凭证是什么、属于谁、本任务申请了什么范围」——除托管 / 轮换 / 吊销外，**产出一条凭证范围声明**（本任务申请范围 + 实际签发范围 + 比对结果）并挂审计链。**为什么**：审计面的**凭证范围**盲区（凭证是否为本任务的**最小授权**）本质是**证据面缺口**——A22 查「有没有提权」查的是权限本身，而「权限与任务的匹配度」需要 Vault 侧的事实才可观测。**事实不可观测时加规则无用**：只会得到永远弃权或永远放行的假规则 |

### 验收标准

- [ ] Agent 沙箱 HTTP 请求经 Vault 动态注入凭证，代码层拿不到 token
- [ ] 凭证轮换/吊销可用
- [ ] `npm test` 全绿
