## 一、CLI 单入口收敛（P0 · 13 bin → `sofagent <域> <动作>` · 2026-09-16 用户拍板排期本版）

> **形态归属**：`[非功能]`（重构·13 bin → 1 + 旧命令 shim 化；shim 退役部分属可拔契约执行面）｜ —

### 问题诊断 / 痛点

📋 **来源**：探索方向表「CLI 单入口收敛（叙事收敛批）」——实测当前 **13 个 bin 条目**（12 个 `sofagent-*` + 1 个裸名 `sofagent` 主入口，实测口径 = 根与各 `engine/*/package.json` 的 `bin` 字段并集）。对用户是 13 个记忆点，新用户第一步摩擦有一半来自「我该用哪个命令」。

**现状与工作量**：裸名 `sofagent` 主入口**已在位**——本章补的是**子命令路由**（域分发到既有实现）与**旧命令 shim 化**，不是从零造入口。

**边界**：旧命令保留**兼容期**（shim 转发 + 弃用提示），不 breaking；bin 面收口与文档面收敛是同一件事。与 v1.5.0 第九章命名债务清扫同属「对外认知面收敛」。

### 实现

| 组件 | 能力 |
|------|------|
| **单入口子命令路由** | `sofagent <域> <动作>` 域分发（audit / train / ontology / evolve / daemon / device / workflow …）路由到既有实现，行为与旧命令一致。**域路由落点在 `engine/umbrella/bin/sofagent.js`**（npm 裸名主入口实体——现为单一转发，非 `engine/core/src/cli.ts`；后者是 `sofagent-core` 的子命令面） |

### 问题诊断 / 痛点

📋 **运行时数据实测发现**（2026-09-16 深挖）：`~/.sofagent/data` 332M 只增不减，三处结构性问题——① `memory/audit` 17178 个事实文件 67M 平铺单目录（dream-cycle `extract-facts` 按 key 前缀分桶后 bucket 内无二级分层、无归档、无轮转，已达文件系统性能退化区间）；② `audit/` 目录三个遗留备份文件 49M（`history.jsonl.bak×2` + `broken-*`）无生命周期策略接管；③ 审计链文件（history 52M / decision-log 56M）永久追加无归档机制。

**边界**：只治理数据文件生命周期，不动链结构本身（HMAC 链只追加不删改是铁律——归档 = 移走历史段 + 锚点重算，非删除）。

## 🔨 核心变更

> **形态归属**：`[主干]`（单入口 CLI 与数据生命周期面）｜ —（发布快照）

### 🧭 CLI 单入口收敛（13 个 bin → 一个入口）
- 13 个 bin 条目收口为 `sofagent <域> <动作>`（15 域 + 7 个保留字直答）；非域首参保持 audit-first 回退，旧写法行为不破
- 12 个旧命令转为转发 shim：可用 + 弃用提示 + 指向新写法，兼容期一个 minor 版本
- 安装态 wrapper 与 npm 裸名合并：装过 install.sh 的机器同样走域路由，不再落「只打 help」的分支

### 🗂️ 数据生命周期治理（数据面不再只增不减）
- 事实记忆二级分层 + 冷热归档轮转，读侧按索引寻址（旧扁平布局零回归）
- 审计链历史段归档：头部段移入 `audit/archive/` 并重算主锚点，归档段带独立锚点可独立校验
- 遗留 `*.bak-*` / `*.broken-*` 按 30 天上限清理，逐条 decision-log 留痕
- doctor 新增数据目录健康度节（单目录文件数 / 总量双阈值黄警 + 修复指引）

### 🔐 沉淀记忆的项目作用域（跨项目不自动共享）
- 审批入池的经验默认钉到项目（按仓库解析），跨项目与用户全局不自动共享——与租户隔离互补的两层默认关
- 确需复用走显式导出/导入，带血缘与审批留痕（fail-closed）

### 📄 运维与安全文档注入（R6）
- HANDBOOK / LIMITATIONS / SECURITY / DEVELOPMENT 四处口径注入（审计留痕 = 判定证据面；巡检 = harness 驻留相位动作）
- LIMITATIONS 新增「S1M 判定失灵面」条目（与 v1.8.0 / v1.9.0 同口径，v2.0.0 §三销账）

### 🔒 BugFix（上版遗留）
- archaeology 门禁修复被发版动作回退的闭环缺口（bump 尾部加回归探针）
- 全局审计信任锚三路死锁解除（恢复指引改可达路径 / doctor 锚刷新不再依赖本地 build / hook 安装指引同步）
- dashboard daemon 健康读取三态修复（消除「读取失败假阳性显示运行中」）
- 文档棘轮 9 项清零 + silent-catch 台账零陈旧 + LangChain 三件 lock 刷新

## ⚠️ 破坏性变更

> **形态归属**：`[主干]`（接口/命令面变更）｜ —（发布快照）

> **升级必读**——四条，其中第一条与第三条各带迁移动作。

- **命令面收敛**：13 个 `sofagent-*` bin 转为**兼容期 shim**（可用但打印弃用提示）——迁移：改用新写法 `sofagent <域> <动作>`（域→子命令全映射表与 12 shim 清单见本章一）；兼容期届满（下一 minor 版本）移除 shim
- **首参语义扩展**：非域首参仍保持 audit-first 回退，但第一个 token 现按「域」解析——迁移：以命令行首词作其他用法的脚本改走完整域映射
- **沉淀记忆作用域默认改项目级**（此前跨项目全局可见）——迁移：跨项目复用改走显式导出 / 导入（`exportFacts` / `importFacts`，带血缘与审批留痕）
- MCP 工具数 **104 → 104**（无新增）
