## 一、经验池接训练管道（instinct→数据集→TrainChannel · 打通 Data-RSI 断链）

> **形态归属**：`[主干]`（判定·数据入池资格与血缘锚点）**+ `[通道]` 成分**（数据集构造与通道提交的执行动作）｜ L1 关档
>
> 📋 **缺口实测（2026-09-19）**：`engine/train/src/dataset-builder.ts` 只吃外部 CSV/XLSX/JSON/文本，**不消费 instinct 池**——Data 面与 Model 面各自为政，一体机数据飞轮（session→分拣→脱敏→数据集→训练→灰度）在「数据集」一环断了内部供给。行业对位：Meta-RSI 的 Data-RSI 是「三算子的共同底料」，其产出同时喂 Harness-RSI 与 Model-RSI。

### 交付

| 组件 | 能力 |
|------|------|
| **instinct 池导出器** | 从 `{SOFAGENT_DATA}` instinct 存储（extractor 产物）筛选高置信度（≥ eval-gate 同源阈值）+ 已考核（第三章）条目，映射为训练记录（pattern→instruction，solution→output），血缘字段（来源轨迹 id / instinct id / 置信度）随行 |
| **dataset-builder 新源** | `instinct` 作为第五种数据源类型接入既有管道（与 CSV/XLSX/JSON/文本并列），复用既有质量闸门与脱敏联动 |
| **TrainChannel 提交接线** | 构造的数据集可经既有 TrainChannel 接口提交（ssh 自管 VM 或托管 API），训练事件照常回流审计链 |
| **血缘锚点** | 数据集 manifest 记录「哪些 instinct 条目进了这个数据集」——训练产物（权重）可反向追溯至经验源头 |

## 二、进化准入判据（检验-生成差距 · 验证便宜的域才自动进化）

> **形态归属**：`[主干]`（判定·准入门）｜ **不可拔**（进化准入门是防「放养式自进化」的缰绳，拔掉它进化链失去安全边界）
>
> 📋 **研究收编**（行业综述定律）：自提升仅在「验证比生成便宜」的域成立——代码/数学有测试套件当免费验证器，开放式写作验证与生成同价、循环空转。对位 sofagent：空房间错误分流器已分「客观错误 vs 主观偏好」，本章把该判据从归因层上移到**准入层**——evolve/skill 晋升在启动前先判定目标域有没有廉价验证器。

### 交付

| 组件 | 能力 |
|------|------|
| **域验证器登记** | 技能/进化目标域声明其验证方式：`deterministic`（测试/编译/断言——廉价）/ `model-judge`（LLM 评分——有成本）/ `human-only`（开放式——必须 HITL）三档 |
| **准入判定** | evolve 晋升与 instinct 注入前按域档位分流：deterministic→全自动走 eval-gate；model-judge→评分 + 采样人审；human-only→强制 HITL，无自动晋升 |
| **fail-closed 语义** | 域未登记验证方式 ⇒ 按最高档（human-only）处理——宁可不进化，不盲目进化 |

### 涉及文件（预估）

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/evolve/src/domain-verifier-registry.ts` | 新建 | 域档位登记 + 准入判定纯函数 |
| `engine/evolve/src/__tests__/domain-verifier.test.ts` | 新建 | 三档分流 / fail-closed / 未登记默认最高档单测 |

### 验收标准

- [ ] 域验证器三档登记可配置（deterministic/model-judge/human-only）
- [ ] 准入判定按档位分流（human-only 域零自动晋升）
- [ ] 未登记域 fail-closed 按 human-only 处理

## 四、出题考核器（instinct 反向生成验证题 · 双成功才入池）

> **形态归属**：`[主干]`（判定·考核规则与入池资格）｜ **不可拔**（考核是经验池的质检门，拔掉等于未经检验的经验直接进训练数据——比放养式自进化更糟）
>
> 📋 **研究收编**（Meta-RSI Data-RSI 环节）：归因→出题→考核三步——按场景/步骤/难度自己写题与答案，只看题尝试复现，「答案成立 + 复现成功」双成功才进全局经验池。对位 sofagent：instinct 链有提取与置信度评分，**缺出题考核环节**——passRate 是被动统计（历史通过率），考核是主动验证（专门构造复现场景）。

### 交付

| 组件 | 能力 |
|------|------|
| **出题器** | 达阈值 instinct 条目反向生成考核题（按 pattern 构造复现场景 + 期望结果），题目落考核队列 |
| **考核执行器** | 只看题不看答案跑复现（deterministic 域跑实际命令/测试；model-judge 域跑评分；human-only 域出题给人） |
| **双成功入池** | 答案校验 + 复现成功双通过 ⇒ 条目标记 `verified` 进经验池（第一章导出器只收 verified 态）；任一失败 ⇒ 降置信度并记失败原因 |
| **与既有链衔接** | 考核态作为 scorer 置信度的新输入维（verified 加权 / failed 减权） |

### 涉及文件（预估）

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/orchestrator/src/instinct/examiner.ts` | 新建 | 出题 + 考核执行 + 双成功判定 |
| `engine/orchestrator/src/instinct/scorer.ts` | 修改 | 置信度加考核态输入维 |
| `engine/orchestrator/src/instinct/__tests__/examiner.test.ts` | 新建 | 出题生成 / 双成功判定 / 失败降级单测 |

### 验收标准

- [ ] 达阈值条目可生成考核题（场景 + 期望结果）
- [ ] 双成功才标 `verified`（答案校验 + 复现各占一票，任一失败降级）
- [ ] 经验池导出只收 `verified` 态（与第一章闭环）
- [ ] 考核态进 scorer 置信度（verified 加权 / failed 减权）
- [ ] `npm test` 全绿
