## 八、跨层证据对账引擎（trace 对账 · 2026-08-30 排入）

> 📋 **2026-08-30 用户拍板**：外部竞争格局核查结论——观测层（Langfuse/Arize/AgentOps）红海且第一方 harness（DSH Trajectory / Claude Code）已标配，sofagent 不做观测产品；但「**观测的对账层**」是结构性空位：被调查系统自己写的日志不能自证清白（EU AI Act Art.12 独立核验叙事 + 2026-07 Hugging Face Agent 逃逸取证 1.7 万次行为重建的行业教训）。定位一句话：**别当摄像头，当法医——吃所有 harness 的轨迹，出同一份判定。**

### 定位

三层证据对齐：**Agent 自述（harness trace：DSH session JSONL / OpenClaw 事件流）vs 独立事实（git diff 审计——已有）vs 模型行为（llm-calls 推理记录 + train_job 训练链——已有）**。观测层回答「Agent 说它干了什么」，审计层回答「实际干了什么」，对账层回答「**说的和干的差在哪**」——第三件事只有 sofagent 能做，因为前两件分别是 harness 和 sofagent 已有。

### 交付

| 组件 | 能力 |
|------|------|
| **trace 接入适配器** | 读 DSH `$DSH_HOME/sessions/`（zstd JSONL 事件流）+ OpenClaw 事件流，解析为统一 trace 模型（turn/step/tool-call/文件操作四类事件）——依托已有 `cordis-plugin-sofagent-*` 9 款插件阵地，DSH 侧是同生态原生读取 |
| **数据 schema 版本化** | trace 相关新增数据源落盘（对账缓存/统一 trace 模型导出）第一行起带 `schemaVersion` 字段——首个破坏性变更出现前不建迁移管道，但版本号先埋上，届时可判可迁（Omarchy migrations/ 机制启发，2026-08-31 排入） |
| **对账引擎（reconcile）** | 三源比对：trace 自述文件操作集 vs git diff 实际变更集 vs task/logs 声明集——产出差异清单（漏报：diff 有 trace 无 / 幻觉动作：trace 有 diff 无且无回滚记录 / 瞒报：logs 声明与 diff 不符） |
| **模型层 trace 对账** | 接 v1.4.1 train_job HMAC 链 + 可复现指纹（datasetHash+环境快照）+ 权重 HMAC 签名：生产推理异常时回溯「该行为出自哪个模型版本 → 哪次训练 → 哪份数据集」全链定责（模型供应链追溯——后训模块交付后独有的能力，观测层玩家做不到） |

### 验收标准

### 竞争定位（为什么这是空位）

- **观测层玩家（Langfuse 等）做不到**：它们的立场是「忠实记录」，加判定就失去中性卖点；且无 git diff 独立事实源。
- **harness 厂商做不到**：DSH/Claude Code 的 trace 是自述证据——「卖锁的不能验锁」，自证清白结构上不成立。
- **sofagent 恰好两件都有**：git-diff 审计（独立事实）+ DSH 插件生态（trace 读取通道）+ 训练链 HMAC（模型层定责）——组合没有第二家。
- **监管窗口**：EU AI Act Art.12 日志义务 2026-08-02 生效；「记录」已法定，「独立核验」是下一站——对账层提前占位。
