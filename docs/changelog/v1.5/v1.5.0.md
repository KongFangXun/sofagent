### 扩展：本体渐进加载三层（商业平台机制对账 · 2026-09-08 排入）

> 📋 **背景**：商业平台待拍板项定义了「本体数据的检索加载深度」（对标 wemux 分形文档 L1/L2/L3，商业三件套已吸收暂定方案）——FDE Agent 召回时一次喂多少：全量喂还是渐进加载？引擎侧零排期，随第二章（本体数据成熟主题）一并落地。

- **三层加载**：① entity 摘要（卡片级：名称 + 类型 + 一句话）→ ② 命中再展开 relations（图结构：关联实体与边类型）→ ③ 确需细读才取页面全文——控制 token 成本，大本体（千级实体）不全量入窗
- **记忆层预算联动**：三层各设 token 预算上限（复用 v1.4.8 自动上下文压缩的预算机制），超预算触发降层（全文→relations→摘要），降层进审计留痕
- **检索协议衔接**：与 interaction 检索协议（语义检索/关键词/图遍历）正交——三层管「喂多少」，检索管「找哪个」
- **验收追加**：千级实体本体下单次召回 token 占用不随实体总量线性增长（三层生效）；预算超限自动降层且留痕；三层内容一致性（摘要与全文同源，无第二份表示）

## 九、命名债务清扫（`@sofagent/harness` → `@sofagent/inject` · harness 同名射程收口）

## 十、DSH 插件事件接线（cordis 对照研究收编 · seam 从声明到实现）

> **形态归属**：`[插件]`（宿主接入面·判定逻辑零改动纯接线）｜ L3 拆件（插件粒度）
>
> 📋 **2026-09-16 排入（用户拍板：事件接线放本版）**。来源：cordis / DeepSeek Harness 对照研究（core 源码三文件精读 + plugin-kit 654 行 + SEAMS.md 全文对照）。**这是 v1.5.0 的插件层收口件**——治理模块把价值面板化（第一至八章），本章把插件层的 seam 从「声明」变成「实现」，两侧对齐。

### 背景与缺口（SEAMS.md §6 自认）

DSH 侧 7 款插件声明 20 个宿主事件位（seam 词汇表），但 `ctx.on()` 真实订阅数 = 0——插件 apply 只做 provide + dynamicCordisRunner + settings 三段式，不注册事件处理器。今天拦截生效的路径是 `engine/orchestrator` 自己的 `wrapToolsWithGate`（sofagent 自家运行时），不走 DSH 宿主事件位。**对外含义**：DSH 原生跑任务时，sofagent 插件挂了也不拦截——「已自动拦截」的文案在 DSH 侧不成立（SEAMS.md §6 尾注自认，落地前不得这样写）。OpenClaw 侧（`api.on('before_tool_call')` 真接线）与 DSH 侧（零订阅）接入深度不同——本章拉平。

### 交付

| 组件 | 改动 |
|------|------|
| **plugin-kit `seamHandlers` 声明面** | `createSofagentPlugin` 入参新增 `seamHandlers?: Record<事件名, handler>`——apply() 内检测到声明时经 `ctx.waterfall(carrier, 事件名, …)` / `ctx.on()` 注册宿主事件订阅；**每次订阅的 disposer 收进既有复合卸载契约**（cordis `ctx.on()` 本身经 `ctx.fiber.effect()` 登记，随插件 fiber 卸载自动撤销——插拔安全由 cordis 机制保证，kit 侧照收 disposer） |
| **audit 插件 4 事件位** | `tools/pre-execute`（执行前拦截——waterfall 可短路拒绝）/ `tools/result`（结果留证）/ `fs/write-intent`（写入前可拦）/ `agent/turn-stopping`（Turn 停止验收判定）——handler 内调既有 bridge API（`@sofagent/audit.runRules` / `define_acceptance` 判定源），**判定逻辑零改动，纯接线** |
| **inject / evolve / rollback 各 1 事件位** | inject → `agent/pre-step`（约束注入，调 `buildConstrainedSystemPrompt`）；evolve → `turn/end`（经验沉淀，调 `generateThinkEntry`）；rollback → `agent/error`（快照回滚，调 `restoreSnapshot`）——同样只接既有 API |
| **SEAMS.md §6 表更新** | DSH 侧行从「声明」改为「声明 + 实现」，尾注「落地前不得写成已自动拦截」随之撤销 |
| **探针剧本扩展** | SEAMS.md §7.3 剧本加事件位验证步（挂探针插件 → 触发 `tools/pre-execute` → 断言拦截生效）——DSH 升级日复验用 |

### 边界（马鞍铁律应用）

接线是**执行面动作**，不改判定逻辑：handler 调用的判定源仍是引擎包（`@sofagent/audit` 等），插件层只加一根管子。审计 24 规则、HMAC 链、ToolGate 矩阵**永不出引擎包**——插件身份判据（能力桥接器 vs 能力实现器，ARCHITECTURE 功能编制节）在本章同样生效。
