## 技术决策

1. **npm unpublish 不可行**：v1.0.1 发布后有依赖包，npm 不允许 unpublish。因此 bump 到 v1.0.2 发布。
2. **原 v1.0.2 规划后推**：原 v1.0.2 规划的"FDE Sub Agent + Audit Sub Agent + SkillOpt"后推到 v1.0.3，后续版本号顺延。
3. **历史引用不改**：ARCHITECTURE.md / ROADMAP.md 等正文中的 "v1.0.1 实现" 是变更溯源标记，不改为 v1.0.2。
