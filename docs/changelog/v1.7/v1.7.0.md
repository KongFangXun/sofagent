## 定位

> 🎯 **判定底座 · RLCD 训练复现**——阶段二第一版，回答「**概率从哪来**」。RLCD（Reinforcement Learning for Calibrated Decisions，用于校准决策的强化学习）与 RLHF、RLVR 的区别在**优化对象的落点**：RLHF 奖励「人更偏好的回答」、RLVR 奖励「可验证的正确结果」、RLCD 奖励「**决策本身及其概率**」——即同时要求判断得准，且准确表达不确定性。**为什么这件事不能用 RLVR 顶替**：判定的正确性往往没有廉价验证器（判据是语义性的），但**概率的良莠可以用评分规则直接度量**——评分规则就是那个廉价验证器。

## 一、训练目标与评分规则（strictly proper scoring rule）

> **形态归属**：`[主干]`（判定·训练目标定义）｜ **不可拔**（奖励定义是模型行为的根约束）

### 交付

| 组件 | 能力 |
|------|------|
| **严格适当评分规则集** | 按原语类型分派损失/奖励：`Noul` 用 **log score**（对数评分，伯努利）；`Choice` 用 **log score + spherical score**（多类分布）；`Score` 用 **RPS**（Ranked Probability Score，有序分档）。**「严格适当」是关键性质**——该性质的数学含义是：报出真实概率时期望得分最优，即**诚实地报概率才是最优策略**，模型没有「虚报高置信度占便宜」的空间 |
| **非对称惩罚（校准的物理机制）** | 奖励对**过度自信**与**犹豫**的惩罚**不对称**：报极端概率（如 0.99）而判错承受**重罚**，报温和概率（如 0.55）而判错承受**轻罚**。优化目标因此不是「答对更多」，而是让**报出的概率收敛到长期统计真实胜率**——这正是「严格适当」在实现层的落法：**诚实报概率是唯一不被惩罚的策略**。副产品是不确定输入下置信度被主动拉低，**调用方因此有条件走 fallback**（与 v1.7.1 弃权语义接续） |
| **策略梯度训练回路** | 以评分规则为奖励的策略梯度优化（**不引入人类偏好模型、不依赖外部教师模型**）——奖励信号完全来自评分规则，训练闭环内无外部依赖 |
| **概率目标消费** | 训练消费 v1.6.1 的**概率目标**（分布/区间/真值概率），而非硬标签——这是 RLCD 与常规监督分类的根本差别 |
| **标注档位加权** | 按 `label.source` 三档加权（`human` > `deterministic` > `model-judge`），权重口径写进配置且可审计 |
| **训练环境** | 默认路径为**云端全参数微调**（算力不构成约束——同类实测量级为单卡 1 epoch 约 1.96 小时）；**LoRA / 冻结编码器**档仅作「客户要求本地训练」时的备选，其对小基座的有效性须实测（见验收） |
| **TrainChannel 提交** | 训练任务经既有 TrainChannel 标准接口提交（不写云厂商适配器——既有边界零改动），训练事件照常回流审计链 |
| **训练可复现** | 固定数据版本 / 评测器版本 / 随机种子 / 超参快照，训练产出自带可复现清单 |

### 验收标准

- [ ] 三类评分规则实现且**严格适当性有断言**（真实概率得分优于偏离概率）
- [ ] **非对称惩罚在位**：极端口径判错的罚分**显著高于**温和口径判错的罚分（有数值断言，防退化为对称惩罚）
- [ ] RPS 用于有序分档（`Score` 原语），序信息被正确利用（非退化为多类 log score）
- [ ] 策略梯度回路可收敛（小规模冒烟：损失单调下降趋势成立）
- [ ] 训练消费概率目标而非硬标签（数据侧断言）
- [ ] `label.source` 加权生效且权重可审计
- [ ] 训练经 TrainChannel 提交，事件回流审计链（既有语义零改动）
- [ ] 训练产物带可复现清单（数据版本 / 评测器版本 / 种子 / 超参）
- [ ] LoRA 档可用性实测落数（小基座上是否有效——如实记录，无效则明确标注为不推荐）
- [ ] `npm test` 全绿

### 风险与前置假设

> ⚠️ **训练量级与数据量的关系必须在动工前确认**。同类参照（开源判定模型基于 9B 基座做 LoRA，参考标签一致率从基座 66.36% 提升到 90.12%）提示：**判定能力对数据质量的敏感度高于对参数量的敏感度**。若 v1.6.1 采集的样本量不足，本版只做小规模验证训练（证明回路可用），**完整训练移交 v1.7.1 与后续版本**，不硬凑。
>
> ⚠️ **本版不承诺准确率数字**。训练目标的科学性是本版交付物，效果数字属 v1.7.1（校准）与 v1.7.2（对比基线）的验收面。
