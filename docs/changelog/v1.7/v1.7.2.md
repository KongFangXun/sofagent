## 定位

> 🧮 **判定底座 · 三原语概率面收口**——阶段二收口版，回答「**概率能不能用**」。v1.7.0 让概率有训练目标、v1.7.1 让概率可信，本版把三原语的概率输出**做完整并对照基线落数**，同时把「概率以什么形态进入判定链」的边界写死。**关键边界**：概率的引入**不扩大证据面**（判定层只能提高已获证据的利用率，不能凭空生成新证据），且输出形态不是 `pass` / `warn` / `fail` 三选一，而是「**概率 + 置信度 + 四态 + 建议动作**」——**只出建议，不执法**。

## 一、三原语概率面完整化

> **形态归属**：`[主干]`（判定·输出形态）｜ **不可拔**（输出契约）

### 交付

| 组件 | 能力 |
|------|------|
| **`Choice` 完整面** | 选中项 + **全候选项归一分布** + 分布熵（低熵=判定明确，高熵=选项间接近→可作为「需复核」信号） |
| **`Score` 完整面** | 分值 + **可信区间**（校准后的分位区间）+ 档位序信息（保序由 v1.7.1 保证） |
| **`Noul` 完整面** | 真值概率 + **四态映射**：`成立` / `倾向成立` / `倾向不成立` / `不成立`——四态由校准后概率分段得出（分段口径 = v1.7.1 的三段门控门槛） |
| **建议动作** | 判定结果附**建议动作**（放行 / 复核 / 转人工 / 阻断）——但建议动作**不具执法力**：执行权仍在既有确定性规则与审计层手里，判定层只提供输入 |
| **不扩大证据面** | 判定输入的 `state` **只含已获证据**（既有审计规则已采集的那些），判定层不新增采集动作、不访问新数据源——**纪律：只提高已获证据的利用率** |
| **结构化可审计** | 输出为结构化类型化记录（choice + 概率 + 置信度 + 四态 + 建议），直接适配既有 decision-log 留痕（类型化输出天然可审计，无需额外解析） |

### 涉及文件（预估）

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/orchestrator/src/router/decision-output.ts` | 新建 | 三原语完整输出形态 + 四态映射 + 建议动作 |
| `engine/orchestrator/src/router/decision-primitives.ts` | 修改 | 补齐分布熵 / 可信区间 / 序信息字段 |
| `engine/orchestrator/src/__tests__/decision-output.test.ts` | 新建 | 四态映射边界 / 建议动作非执法 / 证据面不扩大（行为锁）单测 |

### 验收标准

- [ ] 三原语输出面完整（choice 含分布+熵 / score 含区间+序 / noul 含概率+四态）
- [ ] 四态映射由校准后概率分段得出（分段口径与 v1.7.1 门槛一致）
- [ ] 建议动作**不具执法力**（行为锁：判定输出不直接改变执行结果，需经既有规则/审计层）
- [ ] **证据面不扩大**（行为锁：判定期间无新增数据采集动作）
- [ ] 输出可直接落 decision-log（结构化，无需二次解析）
- [ ] `npm test` 全绿

## 二、对照基线与阶段二收口（如实落数）

> **形态归属**：`[主干]`（判定·度量与收口——本版为**度量与收口动作**）｜ —

### 交付

| 组件 | 能力 |
|------|------|
| **三态对照落数** | 零样本基线（v1.6.2）/ 训练后（v1.7.0）/ 校准后（v1.7.1）三态并列，逐判据对照，**提升幅度如实落数** |
| **双指标分离报告** | 「判定质量」（准确率 / 一致率）与「概率可信度」（ECE / 分桶可靠图）**分列报告**，不合并成单一分数——合并会掩盖「判得准但概率不可信」这类危险组合 |
| **失败模式复扫** | 对比 v1.6.2 的失败模式清单，逐项标注「已解决 / 部分改善 / 未改善」，未改善项连同原因记录（作为 v1.9.1 判据面扩展的输入） |

### 风险与前置假设

> ⚠️ **阶段二可能不达阈，这是排期内的正常分支**。若 v1.7.2 对照显示判定质量或概率可信度未达阈，**阶段三（v1.8.x 接线与分发）不启动**——先把阶段一/二的判据与数据修好。**接线一个不可信的判定模型，比不接线更危险**（它会静默影响分流决策）。
>
> ⚠️ **判定底座永不进信任地基**。其输出可被 `state` 内容操纵（已知失灵面），故架构顺序固定为「**确定性规则在前，语义判定在后**」——既有 24–25 条审计规则的判定面在本阶段**零改动**。
