## 定位

> sofagent 的 ClawHub/SkillHub 分发（SKILL + DSH plugin + OpenClaw plugin 三通道）目前无企业级「谁能装、从哪装」管控。Codex Harness 的 marketplace.json 提供了现成参考：**来源白名单 + 托管 hook 独裁模式**——本版把这套管控引入 sofagent 企业部署（install.sh 企业侧）。

## 行业定位（Codex Harness 启发 · 2026-08-22）

> 📖 来源：[openai/codex](https://github.com/openai/codex) 仓库源码核验（2026-08-22）：
> - `marketplace_policy.rs`：`MarketplaceAllowedSource` 三类来源白名单——Git URL / GitHostPattern（正则）/ Local（绝对路径）
> - `config.md`：`allow_managed_hooks_only = true`（requirements.toml 顶层）——忽略 user/project/session hook 配置，只允许 managed hooks（企业托管独裁模式）
> - `marketplace.rs`：marketplace.json 兼容 `.claude-plugin` / `.cursor-plugin` / `.agents/plugins` 多格式

## 交付

| 组件 | 能力 |
|------|------|
| **插件来源白名单** | 企业侧配置 `plugin_sources.allowlist`（Git URL / 主机模式 / 本地路径三类，对齐 Codex MarketplaceAllowedSource）——白名单外的插件来源安装时拒绝 |
| **托管 hook 模式** | `allow_managed_hooks_only = true` 等价物——企业部署后忽略用户自定义 hook，只跑 sofagent 托管审计 hook（对齐 Codex requirements.toml） |
| **分发通道统一管控** | 管控同时覆盖 ClawHub（OpenClaw plugin 家族）+ SkillHub（DSH plugin 家族）——白名单判断在安装侧生效，不依赖平台侧 |
