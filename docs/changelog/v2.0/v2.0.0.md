## 定位

> 🏁 **S1M 宣告大版本**——V2.0.0 只做一件事：**宣告身份切换**。产品从「审计引擎 harness」（FDE Harness——治理 7×24 无人值守部署的 AI 节点）升级为 **FDEing × S1M × Harness**——「基于 FDEING 的能力，打造一个 harness 与决策模型」：FDEing 是能力底座（把 FDE 的进场判断力产品化、流程化的工作流能力），**S1M 是本体（System One Model——判据集 · 三原语 · 校准概率 · 弃权语义；命名承接判断与生成分离的行业谱系，见 §一）**，Harness 是治理环境（约束层五能力：注入·审计·回溯·沉淀·进化）。判定底座施工期（v1.6.0–v1.9.0）已把「本体」造完；本版不再新增判定能力，只做四件事：**宣告（§一）· 术语清洗（§二）· 对外叙事重定位（§三）· 原规划去向落盘（§五）**。**为什么身份切换值得一个独立版本**：v1.9.0 §八已论证——术语全站统一后「切换时不需要再做一轮术语清洗」，且「形式上成立却内容未达阈时宣告，等于把叙事跑在实现前面」；本版就是那个「达阈之后的宣告动作」本身。**宣告的资格链**：v1.5.x 备载体（治理环境）→ v1.6.0–v1.9.0 装本体（判定底座）→ 本版宣告「本体与载体合一」。**V2.0 后的版本域纪律**：V2.0 起全部是 S1M 的迭代域——V2.0 前的能力不放 V2.0 后的版本去迭代；V2.0 后做什么暂不定义，由 S1M 自身的产品化需求驱动。
