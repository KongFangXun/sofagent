## 核心变更

### P0 修复（5 项 · 发版阻断）

#### 问题 1 · webhook PASS 推送接通

**问题**：`webhook.ts:22` 注释声称"v1.1.3: PASS 也推送"，`pushAuditResult` 内部 `isPass` 分支齐全，但 `index.ts:668` 调用层条件 `if (results.exitCode > 0 && ...)` 把 PASS 挡在门外——能力具备但从未接通。

**修复**：`sofagent/audit/src/index.ts:668-669` 去掉 `results.exitCode > 0` 条件，PASS/WARN/FAIL 三态都推。

**文件变更**：

| 文件 | 变更 |
|------|------|
| `sofagent/audit/src/index.ts` | webhook 推送条件从 `results.exitCode > 0 && args.webhook && args.webhookUrl` 改为 `args.webhook && args.webhookUrl` |
| `sofagent/audit/src/webhook.test.ts` | 新增 3 场景测试（PASS/WARN/FAIL 各推一次验证） |

#### 问题 2 · --init 文案规则数动态读取

**问题**：`commands/init.ts:120` 写"11 条规则"，实际 `defaultRules` 数组 13 条——自打嘴巴。

**修复**：改为 `${defaultRules.length}` 动态读取，根治漂移。

**文件变更**：

| 文件 | 变更 |
|------|------|
| `sofagent/audit/src/commands/init.ts` | 顶部 import `defaultRules`；第 120 行文案改为模板字符串动态读取 |
| `sofagent/audit/src/fix-suggestions.ts` | 注释从"11 条规则各自的"改为"每条规则的（覆盖随 defaultRules 动态扩展）" |
| `sofagent/audit/src/qa-boundary-verify.test.ts` | 测试文案从硬编码"11"改为 `defaultRules.length` 模板字符串 |

#### 问题 3 · "knowledge resource" → "knowledge tool" 全仓清零

**问题**：CHANGELOG v1.1.5.md 声称"7 个 knowledge resource"，实际这 7 个全部注册为 tools（mcp-server.ts），不是 resources。`handleResourcesList` 实际只返回 4 个 resource。

**修复**：全仓 24 处"knowledge resource"统一改为"knowledge tool"。

**文件变更**：CHANGELOG.md、docs/changelog/v1.1.5.md（5 处）、docs/changelog/v1.1.6.md、docs/changelog/v1.1.9.md、ROADMAP.md

#### 问题 4 · CHANGELOG 索引 v1.1.5 重复条目删除

**问题**：CHANGELOG.md 中 v1.1.5 同时出现在已发版区（line 10）和规划中区（line 113），规划中条目是发版前草稿忘删。

**修复**：删除规划中段的 v1.1.5 条目（line 113-117）。

#### 问题 5 · v1.1.5 changelog 清理过程元信息

**问题**：v1.1.5 的 changelog 子文件自身含过程元信息（旧标题用内部审查编号命名章节）。

**修复**：章节标题、表格编号、正文措辞全部改为产品语言（"问题 N""发布后问题修复"等）。
