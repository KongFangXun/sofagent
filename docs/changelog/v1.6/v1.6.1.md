## 定位

> 🧱 **判定底座 · 数据集三元组与三源采集**——阶段一第二版。v1.6.0 定义了「要判断什么」，本版解决「**拿什么训练**」：把判据样本化为统一三元组，并从约束层**已有的运行痕迹**里采集标注，而不是靠人工从零标注。**关键洞察**：约束层自己就在生产训练数据——history 轨迹、HITL 人工裁决、PR 审阅结论都是天然标签，本版只是把它们接起来。

## 一、数据集三元组格式（状态 / 问题集 / 标注答案）

> **形态归属**：`[主干]`（判定·数据格式）｜ **不可拔**（格式是数据集契约，拔掉则标注无法被校验）

### 交付

| 组件 | 能力 |
|------|------|
| **三元组定义** | `(state, questions, answers)`——`state` 为非结构化输入快照、`questions` 为限定原语类型的问句集、`answers` 为类型化答案（含概率目标）。与 v1.6.0 三原语类型同构，**不另立格式** |
| **标注来源三档** | `label.source` 三档与 v1.5.14 域验证器口径一致：`deterministic`（自动判据/测试断言 → 廉价可信）/ `model-judge`（模型评分 → 有成本）/ `human`（HITL 裁决、PR 审阅 → 最贵最可信）。**分档随样本走**，训练时可按档加权 |
| **概率目标表达** | `answers` 须能表达**概率目标**（choice 的分布 / score 的区间 / noul 的真值概率），而非单一硬标签——这是阶段二校准训练的前置条件。只有硬标签的数据集**训不出校准**，格式层必须预留 |
| **血缘锚点** | 每条样本记录反向锚点（轨迹 id / instinct id / PR 号 / HITL 会话 id），与 v1.5.15 数据集血缘同族——训练产物可反向追溯至样本源头 |
| **租户隔离** | 样本按 `enterpriseId` 分区（对齐 v1.4.7 多租户路径纪律），跨租户混入默认禁止 |
| **格式校验器** | 数据集加载时断言：三元组齐全、问句类型合法、答案类型与问句匹配、概率目标合法（分布归一 / 区间有序 / 概率 ∈ [0,1]）；不合规 → **拒绝加载** |

| `engine/orchestrator/src/router/decision-dataset-schema.ts` | 新建 | 三元组格式 + 概率目标表达 + 校验（fail-closed） |

## 二、三源采集器（history / HITL / PR）

> **形态归属**：`[主干]`（判定·样本来源判定与来源真实性门）**+ `[通道]` 成分**（采集与落盘的执行动作）｜ —

### 交付

| 组件 | 能力 |
|------|------|
| **history 采集** | 从历史执行轨迹（含 v1.5.0 交付的 trace 与因果链）抽取 `(state, questions, answers)`——状态从轨迹最小可判定前缀取，答案是**当时实际发生的处置** |
| **HITL 采集** | 从人工裁决记录（v1.3.7 起 HITL 通道）抽取——人工批准/拒绝是最高可信档 `human` 标签，**直接可作校准的真值来源** |
| **PR 采集** | 从 PR 审阅结论（v1.3.x 起 pr-store 的审阅结论与 suggestion 采纳情况）抽取——采纳/拒绝构成标签 |
| **来源真实性门** | 只收**经审计链锚定的真实运行痕迹**派生的样本；合成 / Agent 自述 / 未建链来源标记后**默认拒收**（与 v1.5.15 防自证污染同源纪律：数据来源未标记 ⇒ 按不可信处理 fail-closed） |
| **去重与泄漏防护** | 采集侧做近重复检测；**同一轨迹不得同时进训练集与验证集**（数据泄漏防护）——切分按轨迹/租户粒度而非样本粒度 |
| **采集可观测** | 各源采集量 / 各档占比 / 拒收原因分布可查询（数据面健康度可见，数据本地不出门） |

### 验收标准

- [ ] 三源各自可抽取三元组，产出格式与 §一 校验器兼容
- [ ] 来源真实性门生效：未建链 / 合成来源 fail-closed 拒收，拒收原因可查
- [ ] HITL 源样本标记为 `human` 档（最高可信档）
- [ ] **同一轨迹不跨训练/验证集**（按轨迹粒度切分，泄漏防护有单测）
- [ ] 采集量 / 档位占比 / 拒收原因可观测
- [ ] 租户隔离生效（跨企业样本不混入）
- [ ] `npm test` 全绿

### 风险与前置假设

> ⚠️ **本版产出的样本量可能不足**——三源采集依赖真实运行积累，早期客户环境样本稀疏。若样本量不足以支撑阶段二校准，则**下调阶段二目标（只出判定不出校准）并把校准后移**，不硬训。样本量实测结论作为 v1.6.2 的基线输入之一。
