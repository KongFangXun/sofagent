## 修复清单

### P0（3 项）

#### P0-1：release.yml CI E403 根治——加版本存在性检查

- **问题**：release.yml 两个 job（audit + mcp）的 `npm publish` 步骤 10 次全失败，报 E403（版本已存在）。根因：CI 不检查版本是否已发布就直接 publish
- **修复**：新增 `Check if version already published` 步骤，用 `npm view @sofagent/audit@${VERSION}` 检查，已发布则 `skip=true` 跳过 publish。同时删除 `id-token: write`（死代码，实际用 NPM_TOKEN）
- **文件**：`.github/workflows/release.yml`

#### P0-2：OIDC 文档谎言清零——12+ 处统一改为 NPM_TOKEN

- **问题**：release.yml 实际用 `NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}` 发布，但 releasing.md、SOFAGENT_VERSION_SOP.md、CHANGELOG.md、ROADMAP.md、docs/changelog/v0.99.6.md 共 12+ 处声称使用 OIDC Trusted Publishing——文档与实际严重矛盾
- **修复**：全仓 OIDC 残留清零（排除历史 changelog）。故障表「OIDC 认证失败」→「npm publish 403」。needs 描述「mcp job 依赖 audit job」→「mcp job 独立于 audit job」
- **文件**：`docs/releasing.md` + `docs/SOFAGENT_VERSION_SOP.md` + `CHANGELOG.md` + `ROADMAP.md` + `docs/changelog/v0.99.6.md`

#### P0-3：回滚与降级流程文档缺失

- **问题**：releasing.md 无回滚章节——npm 包发布后发现严重 bug，没有标准回滚流程
- **修复**：新增完整「回滚与降级」章节：npm deprecate + dist-tag + git revert + ClawHub/SkillHub 四通道 + 时间预估表
- **文件**：`docs/releasing.md`

### P1（4 项）

#### P1-1：mcp 依赖版本解锁——精确改范围

- **问题**：mcp package.json 中 `@sofagent/audit: "0.99.6"`（精确版本），每次 audit bump 版本，mcp 必须手动跟着改
- **修复**：改为 `@sofagent/audit: "^0.99.6"`（范围版本），audit patch/minor 升级 mcp 自动兼容
- **文件**：`sofagent/mcp/package.json` + `package-lock.json`（npm install --package-lock-only 同步）

#### P1-2：package-lock.json 同步

- **问题**：mcp 依赖改 ^0.99.6 后，根 package-lock.json 未同步（lock 中仍是 0.99.5 精确版）
- **修复**：`npm install --package-lock-only`，lock 中 `sofagent/mcp` dependencies 同步为 `^0.99.6`，version 更新为 `0.99.6`
- **文件**：`package-lock.json`

#### P1-3：releasing.md 悬空引用修复

- **问题**：releasing.md 写「见下方步骤 f」，但下方无步骤 f——悬空引用
- **修复**：改为「见下方「npm 双包验证」步骤」
- **文件**：`docs/releasing.md`

#### P1-4：Tag 卫生——v0.7.0/v0.7.1 改名

- **问题**：git tag `v0.7.0`/`v0.7.1` 与 semver 不一致（应为 `v0.70.0`/`v0.70.1`）
- **修复**：`git tag v0.70.0 v0.7.0`（改名）+ `git tag -d v0.7.0 v0.7.1`（删除错误 tag）+ `git push origin v0.70.0`（推远程）
- **文件**：git tags

### P2（4 项）

#### P2-1：Windows 实验性诚实标注

- **问题**：README 声称全平台支持，但 verify.ps1 仅 230 行 vs verify.sh 942 行（4:1），PowerShell 功能严重不等价
- **修复**：README.md Quick Start 区新增平台支持声明（macOS/Linux 全功能，Windows 实验性）；LIMITATIONS.md 新增「Windows 支持是实验性的」章节，含 .sh vs .ps1 行数对比表
- **文件**：`README.md` + `LIMITATIONS.md`

#### P2-2：shellcheck SC2034 全部清除

- **问题**：7 个 shell 脚本存在 SC2034（未使用变量）警告
- **修复**：
  - `cleanup.sh`：删除未使用的 `PURGE` 变量
  - `fde-install.sh`：删除未使用的 `RED` 颜色变量
  - `platform-detect.sh`：加文件级 `# shellcheck disable=SC2034`（变量被 source 到 install.sh 主体使用）
  - `daemon-install.sh`/`daemon-status.sh`/`daemon-uninstall.sh`：加 disable 注释
  - `install.sh`：删除无用的 `CONFIG_FILE=""` 预声明
- **验证**：`find ... | xargs shellcheck ... | grep SC2034` 输出为空
- **文件**：7 个 shell 脚本

#### P2-3：logo 压缩 84%

- **问题**：`index/sofagent.png` 334KB（710×710px），README 展示宽度仅 300px——严重过大
- **修复**：PIL 量化压缩——缩放到 400×400px（支持 retina）+ 量化到 128 色 + 恢复 alpha 通道。334KB → 52KB（减少 84%），透明度保留
- **文件**：`index/sofagent.png`

#### P2-4：orchestrate-compare.ts 注释修正

- **问题**：注释写「优先匹配关键词回退 emoji」，实际代码是同时匹配取并集（OR）
- **修复**：改为「同时匹配文字关键词（中/英文）和 emoji，取并集（OR），两者出现任一即计入」
- **文件**：`sofagent/audit/src/orchestrate-compare.ts`
