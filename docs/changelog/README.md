## ⚠️ 规划中版本的阅读须知

标 `⚠️ 尚未实现` 的文件是**规划中的开发排期**，**尚未实现**。打开这些文件看到的功能描述不代表当前版本能力——当前版本的实际能力以 [`../../README.md`](../../README.md) 和 [`../ARCHITECTURE.md`](../ARCHITECTURE.md) 为准。规划中版本的正式排期见 [ROADMAP](../ROADMAP.md)。

**判定底座施工期（`v1.6/` – `v1.9/`）的两条排期纪律**：

1. **颗粒度以「可独立验收的交付单元」为界**——四阶段各一版，单版内容不硬凑章数。阶段内可增补补丁位（`vX.Y.1`），阶段间可插入新阶段，**编号不重排**（详见 [ROADMAP · 判定底座施工期](../ROADMAP.md#判定底座施工期v160--v190--四阶段四版)）。
2. **未达阈不加宣告**——各版验收标准中的硬线（如阶段二的校准硬线、阶段三的权重完整性校验）未通过时，**增补版本而非放宽标准**；形态宣告的时点由「四阶段收口达阈」决定，不由版本号决定。
