## ⚠️ 规划中版本（v1.4/）的阅读须知

`v1.4/` 下的文件是**规划中的开发排期**，**尚未实现**。打开这些文件看到的功能描述不代表当前版本能力——当前版本（v1.3.3）的实际能力以 `../../README.md` 和 `../ARCHITECTURE.md` 为准。规划中版本的正式排期见 [ROADMAP](../ROADMAP.md)。

## 历史版本日志的阅读须知

早期版本日志（v1.0/v1.1）含"审查元信息/开发过程备注"等非产品文档内容，属当时开发留痕，不代表产品能力声明。✅ **v1.3.3 起已清理审查元信息**（见 v1.3.4 bugfix），当前版本 changelog 只含产品变更声明。以各版本 changelog 顶部的"已开发/已排期"标记为准。
