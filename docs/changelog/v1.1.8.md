# v1.1.8 开发日志 — USB 完整运行时

> 状态：规划中 · 孔放勋 · 2026-07-15
> 前置依赖：v1.1.7（安全加密 + 联邦查询已就绪）+ v1.1.3（USB federation 已就绪）

## 背景

v1.1.3 的 USB 检测只能做初始配置（插 U 盘 → 自动读取 federation.json）。v1.1.7 的加密和联邦查询已经让设备间能安全通信。现在把它们全部打包进 U 盘——插到任何电脑上，双击就能跑完整的 sofagent + OpenClaw，不需要安装任何东西。

## 交付：USB 完整运行时（P0）

**产品形态**：企业下载 sofagent → 写入 U 盘 → 发给员工。员工插上任何电脑，双击 `start` → 3 秒后联邦在线。拔掉 U 盘，电脑零残留。

```
IT 部门操作（一次性）：
  sofa-federation create-usb-key --role "财务审计节点"
  → 写入 U 盘：Node.js 单文件 + OpenClaw + sofagent + federation.json + 空 knowledge/

员工体验：
  拿到 U 盘 → 插进电脑 → 双击 start → "已连接联邦，共 3 台设备在线"
  下班 → 拔掉 U 盘 → 电脑不留任何痕迹
```

### 实现

| 组件 | 技术方案 |
|------|------|
| Node.js 单文件打包 | pkg / nexe，目标 macOS + Linux + Windows |
| OpenClaw 便携化 | 读 U 盘相对路径配置，不依赖 `~/.openclaw` |
| sofagent 运行时 | 从 U 盘路径加载 federation.json + knowledge/ |
| 跨平台启动脚本 | `start.command`（macOS）/ `start.bat`（Windows）/ `start.sh`（Linux） |
| daemon 自动启动 | 双击后 daemon 后台运行，保持联邦在线直到拔出 |

### 安全：HMAC 内容签名 + 磁盘加密

**HMAC 防篡改**——`create-usb-key` 写入完成后，自动计算所有文件的 HMAC-SHA256 签名写入 `/.sofagent-signature`。daemon 每次启动先验签——签名不匹配 → 拒绝启动并记录安全事件。「不能阻止物理删除，但删了就废。」

**磁盘加密防失窃**——U 盘 knowledge/ 目录在写入时用 federation.json 中的 AES-256 密钥加密。daemon 启动后内存解密读写，U 盘文件系统上永远只有密文。U 盘丢失 = 拿到盘的人读不到任何知识。

| 攻击场景 | 防线 |
|------|------|
| 偷 U 盘插自己电脑看文件 | knowledge/ 全盘 AES 加密，无密钥不可读 |
| 删掉 federation.json 试图重置 | HMAC 签名不匹配，daemon 拒绝启动 |
| 往 U 盘拖入恶意文件 | 多余文件 → HMAC 签名不匹配 |
| 整盘格式化重写 | 签名文件消失 → daemon 检测不到 → 拒绝启动 |
