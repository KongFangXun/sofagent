# v1.0.8 开发日志 — 文件系统审计 + 内嵌 isomorphic-git + Agent 定义去耦合

> 审计引擎从"只有 git commit 才触发"扩展为"任何文件变更都触发"。内嵌 isomorphic-git 让非开发者也能用——不需要装 git、不需要 commit、不需要写代码。同时完成 Sub Agent 定义去 OpenClaw 耦合。
>
> 待开发 · 孔放勋

---

## 背景

sofagent v1.0.7 及以前，审计引擎只在 `git commit` 时触发（commit-msg hook）。这意味着：

1. **非开发者用不上**——客服、运营、数据分析人员用 AI 改 Excel/Word/报告，不产生 git commit，审计引擎完全看不到
2. **审计只在开发者世界工作**——电脑上必须装 git，用户必须有 commit 行为

v1.0.8 的核心突破：**文件系统审计**。daemon 监控指定目录的文件变更，变更发生时直接跑审计——不需要 git commit，不需要用户操作，完全被动。内嵌 `isomorphic-git`（纯 JS Git 实现，~2MB）作为 diff 引擎，非 git 目录也能做行级差异分析。

## 交付内容（5 件事）

### 1. 内嵌 isomorphic-git

`@sofagent/audit` 的 dependencies 新增 `isomorphic-git`（MIT，纯 JS 实现）。

**为什么不用系统 Git**：

| 方案 | 体积 | 需要系统装 Git？ | 二进制依赖 |
|------|------|:---:|:---:|
| 系统 `git` 命令 | 0（已有） | ✅ 必须 | ❌ |
| **isomorphic-git** | ~2MB | ❌ 不需要 | ❌ 纯 JS |
| libgit2（node-git） | ~5MB | ❌ | ✅ native addon 需编译 |

sofagent-audit 已有 Node.js 运行时，内嵌 isomorphic-git 后用户零额外安装。

**改动文件**：
- `package.json`：dependencies 加 `"isomorphic-git": "^5.x"`
- `diff-parser.ts`：新增 `generateDiff()` 函数，内部用 isomorphic-git 在临时 repo 做 diff

**实现要点**：
- 非开发者场景：daemon 在工作目录下 init 隐藏 repo（`.sofagent/.git-shadow/`），每次文件变更后 add + diff
- 开发者场景：仍然优先用系统 git（性能更好），isomorphic-git 仅作为 fallback
- 不暴露 git 操作给用户——用户永远不需要知道有 git 存在

### 2. daemon 文件系统监控（fs-watch）

daemon 新增文件系统监控模块，监听配置的目录变更：

```typescript
// daemon/fs-watch.ts（新增）
import chokidar from 'chokidar';

const watcher = chokidar.watch(watchPaths, {
  ignored: [/node_modules/, /\.sofagent\/\.git-shadow/, /\.git/],
  persistent: true,
  ignoreInitial: true,
});

// 防抖：连续变更合并为一次审计
let debounceTimer: NodeJS.Timeout;

watcher.on('all', (event, path) => {
  clearTimeout(debounceTimer);
  debounceTimer = setTimeout(() => {
    runFilesystemAudit(changedFiles);
  }, 5000); // 5 秒防抖
});
```

**配置文件**（`.sofagent/watch.yml`，新增）：

```yaml
# 监控的目录（相对于项目根）
paths:
  - "./"
  - "./docs/"

# 排除的文件/目录
ignore:
  - "node_modules/"
  - ".sofagent/.git-shadow/"
  - "*.tmp"

# 防抖时间（毫秒）
debounce_ms: 5000

# 审计模式：text-only | all
# text-only: 只审计文本文件（.md/.ts/.js/.json/.yaml/.csv 等）
# all: 也审计二进制文件（行为级规则，v1.0.9 实现）
mode: text-only
```

**设计要点**：
- `chokidar` 跨平台（macOS fsevents / Linux inotify / Windows ReadDirectoryChangesW）
- 5 秒防抖：AI 批量改文件时合并为一次审计，避免逐文件触发
- 文本文件判定：按扩展名 + MIME type（`text/*` + 常见代码/文档格式）
- 文本文件变更 → 生成 diff → 跑现有 A1-A15 规则
- 二进制文件变更 → v1.0.8 只记录到 history.jsonl（`"binary_change"` 事件），v1.0.9 加行为级规则

**审计语义变化**（诚实声明）：

| 维度 | git commit 审计（v1.0.7） | 文件系统审计（v1.0.8） |
|------|------|------|
| 触发 | 用户主动 commit | 文件写入自动触发 |
| 拦截能力 | ✅ 阻断 commit | ❌ 文件已改完，只能告警 |
| 回溯能力 | ✅ git 历史 | ✅ isomorphic-git 快照 |
| 证据 | git diff（硬证据） | 文件 diff（硬证据） |
| 适用人群 | 开发者 | 开发者 + 非开发者 |

**文件系统审计是事后告警，不是事前拦截**——文件已经改完了，审计发现违规后告警 + 可选回滚建议。这是架构层面的诚实声明。

### 3. 快照回溯

每次文件变更审计完成后，daemon 自动做一次 git 快照（`isomorphic-git commit`）：

```typescript
// daemon/snapshot.ts（新增）
async function createSnapshot(repoDir: string, auditResult: AuditResult): Promise<string> {
  const { commit } = await import('isomorphic-git');

  // 审计通过 → 快照标记为 verified
  // 审计告警 → 快照标记为 warned（仍然快照，只是标记不同）
  const sha = await commit({
    fs,
    dir: repoDir,
    message: `audit-snapshot: ${auditResult.exitCode === 0 ? 'PASS' : 'WARN'} ${new Date().toISOString()}`,
    author: { name: 'sofagent-daemon', email: 'daemon@sofagent.local' },
  });

  return sha;
}
```

**快照用途**：
- 用户可以 `sofagent-audit --revert <snapshot-sha>` 回滚到任意快照
- `sofagent-audit --history --visual` 查看快照时间线（v1.0.9 实现可视化）
- 快照存储在 `.sofagent/.git-shadow/`，不污染用户的 git 仓库

**不做的**：
- ❌ 不自动回滚——回滚是人的决策
- ❌ 不上传快照到任何远端——纯本地
- ❌ 不对用户的 .git 做任何操作——隐藏 repo 是独立的

### 4. Agent 定义去 OpenClaw 耦合

Sub Agent 的 4 个定义文件（`agents/*.md`）移除 OpenClaw `session.spawn` 耦合，改为纯 DeepAgents 定义。

| 文件 | 改动 |
|------|------|
| `engineering-minimal-change-engineer.md` | 移除 session.spawn 引用，改为 DeepAgents `agent.spawn()` |
| `engineering-code-reviewer.md` | 同上 |
| `forward-deployed-engineer.md` | 同上 |
| `security-compliance-auditor.md` | 同上 |

这样 Sub Agent 可以在非 OpenClaw 节点（个人增强节点）上直接运行，不需要 OpenClaw 的 session API。

### 5. TencentDB Agent Memory 集成

sofagent 的 knowledge/ 从"手写百科"变成"自动生长的知识库"。daemon 自动同步 persona.md，加载链注入用户画像。

**前提条件**：

| 条件 | 状态 |
|------|------|
| OpenClaw 已安装 TencentDB 插件 | ✅ 已装（v1.0.0，enabled） |
| `~/.openclaw/memory-tdai/` 目录存在 | ⏳ 待对话产生记忆数据后自动生成 |
| persona.md 格式稳定 | ⏳ 跑 3-5 天对话后验证 |

**交付内容**：

1. daemon Ingest 加扫描源：检测 `~/.openclaw/memory-tdai/persona.md` 的文件 hash 变化 → 同步到 `knowledge/entities/persona.md`
2. 加载链第 4 层注入 persona.md 前 500 字
3. install.sh 加 `--with-memory` 可选参数

> ⚠️ v1.0.8 开发前必须先在 OpenClaw 上跑 3-5 天对话，确认 persona.md 产出质量。
