## 定位

> 🧩 **判定底座 · 既有判定面收敛**——阶段四第一版，回答「**已有的那些判定能力怎么办**」。实测普查（2026-09-20）的结论是：引擎里 Choice / Score / Noul 三种原语的**形状全都已经存在**——`fde_classify` 的「三问输入 → 三选一输出」已是 Choice + Noul 的组合、`evaluate` / `quality-judge` 是 Score、`shouldAllow` 是 Noul——**但三者共缺同一个维度：校准概率**。本版把已有判定面接上判定底座，同时完成一件更重要的诚实性工作：**把「假概率」正名**。

## 一、三原语既有实现补概率（形状已有，补上第三维）

> **形态归属**：`[主干]`（判定·既有面收敛）｜ **不可拔**（判定输出契约）

### 交付

| 既有能力 | 现状（实测） | 本版收敛 |
|----------|-------------|----------|
| **`Choice`**——`fde_classify` | 三问布尔输入 → 三选一（🔄自动 / ⚡强化 / 👤暂不动），**无概率** | 保留三选一语义，补**全候选项分布**；输入三问由布尔升级为**可带概率**（保留纯布尔兼容路径，不破坏既有调用方） |
| **`Score`**——`evaluate` / `evaluate_output` / `quality-judge` | 裸分值，**无不确定度** | 补**可信区间**（校准备用）与档位序信息；分值口径与既有保持不变，纯增量 |
| **`Noul`**——`shouldAllow` / 规则 verdict | 纯布尔（`allow: boolean` + `requireApproval: boolean`），**无概率** | 保留布尔结果（**执行语义零改动**），并列输出**判定成立概率**——布尔仍是执行依据，概率是复核与分流的输入 |
| **判定源统一** | 三处各自实现，无共同底座 | 三类判定统一路由到判定底座（`DecisionChannel`）；**降级路径保留**（判定底座不可用时退回既有确定性实现，行为与今日一致） |
| **确定性规则不动** | 24–25 条审计规则判定面 | **零改动**（本版只补概率维度，不改规则语义与执行顺序——确定性规则在前，语义判定在后） |

## 二、假概率正名（诚实性工作 · 不伪造校准）

> **形态归属**：`[主干]`（判定·数值语义正名）｜ **不可拔**（数值语义失真会误导下游门槛设计）

### 实测现状（2026-09-20 普查）

引擎内散布的置信度数值，**没有一个是校准概率**，且分三类不同性质：

| 性质 | 实测样例 | 正确处置 |
|------|----------|----------|
| **硬编码常数** | 根因分析内 `confidence: 0.7` / `confidence: 0.6` 等直接写死的数值 | 属**启发式权重**，非概率——**正名为权重**，或接入校准后替换 |
| **枚举映射出的数值** | PR 触发绑定两态枚举映射为 `1.0` / `0.5`；决策 schema 的 `'high' \| 'med' \| 'low'` 三态 | 属**序数等级**，非概率——**保留等级语义**，导出数值时标注为序数而非概率 |
| **真概率字段** | **全仓零命中** | 本版起由判定底座补齐 |

### 交付

| 组件 | 能力 |
|------|------|
| **语义正名** | 按上表三类分别处置：能校准的接校准（v1.7.1 能力），本质是权重/等级的**正名为权重/等级**——**不把权重伪装成概率** |
| **调用侧可分辨** | 数值携带语义标记（`probability` / `heuristic-weight` / `ordinal-level`）——下游按标记决定能否进概率门槛，**标记缺失按不可信处理** |
| **门槛口径校正** | 既有以这些数值为门槛的判定（若有）重新校准口径：用权重当概率设门槛的，门槛含义须改写为「按经验阈值」而非「按错误率」——**说清它是什么** |
| **普查清单落盘** | 全部既有置信度数值逐条登记（位置 / 当前值 / 性质 / 处置），落文档可核对——**数量与位置如实落数，不概括为「若干处」** |
| **不静默改行为** | 正名**不改变既有判定行为**（只改语义标记与文档口径）；需要改行为的，单独列变更并留痕 |

### 风险与前置假设

> ⚠️ **本版的产出是「诚实」而非「更强」**。正名后的数字可能看起来「更弱」（从 `0.7` 变成「一个启发式权重」），但这是必要的——把权重当概率用于分流门槛，会让门槛的含义从根本上失真，错误率无法预测也无法举证。
>
> ⚠️ **本版不改判定行为**。行为收敛若需要，属后续版本独立评估——把「语义正名」与「行为改变」混在一版，会让回归问题无法定位。
