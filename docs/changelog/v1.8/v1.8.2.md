## 一、权重分发通路（补唯一缺口）

> **形态归属**：`[主干]`（分发·制品通路）｜ **不可拔**（制品通路是交付形态的最后一环）

### 交付

| 组件 | 能力 |
|------|------|
| **manifest 远端源字段** | `weights-manifest` 补 `remote` 字段（源地址 / 制品 id / 版本 / 期望 sha256 / 大小）——既有 `versions[]`（id / createdAt / sha256 / sizeBytes）与 `current` 结构不变，**纯增量** |
| **下载组件** | 从远端拉取权重的下载件：**断点续传** + 失败重试 + 进度可见；接续 v1.4.2 已排期的「基座模型下载管理」 |
| **完整性与篡改检测** | 下载后按 `sha256` 校验（复用既有 `hashDir()` 目录级哈希口径），不匹配 → **拒绝启用并留痕**（fail-closed，不静默替换） |
| **多版本与回滚** | 复用既有 `model_switch` 多版本能力：可并存多版权重、可回滚到上一版（既有「供应链红线」纪律零改动） |
| **来源白名单** | 远端源须在白名单内（默认只允许既定主载域），非白名单源须显式开启且留痕——防供应链投毒 |
| **版本松耦合** | 权重版本独立于 sofagent 代码版本：接口契约由 `DecisionChannel` 保证，**不由版本号保证**——v1.7 训出的权重可挂到 v1.8/v1.9 的代码，也可回挂（只要契约未变） |

### 三层分发物（制品架构）

| 层 | 载体 | 版本节奏 | 体量 |
|----|------|----------|------|
| **代码包** | npm + 仓库 tag | 随 sofagent 版本 | MB 级 |
| **规则资产** | 随代码走（判据 / 规则 / 校准声明） | 随代码版本 | KB 级 |
| **模型制品** | **权重主载于模型托管平台**（权重本体）+ **仓库内只放权重清单 / sha256 / 模型卡** | **独立版本号**（与代码松耦合） | GB 级 |

### 涉及文件（预估）

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/orchestrator/src/weights/weights-manifest.ts` | 修改 | 补 `remote` 字段（纯增量，既有结构不变） |
| `engine/orchestrator/src/weights/weights-fetch.ts` | 新建 | 下载件（断点续传 / 重试 / 进度 / 来源白名单） |
| `engine/orchestrator/src/weights/__tests__/weights-fetch.test.ts` | 新建 | 断点续传 / sha256 不匹配拒绝 / 白名单断言 |
| `weights/README.md`（或既有位置） | 新建/修改 | 权重清单 + sha256 + 模型卡（仓库内只放这三样） |

### 验收标准

- [ ] `weights-manifest` 的 `remote` 字段可用（既有字段零破坏，纯增量）
- [ ] 下载件支持断点续传与失败重试（有单测）
- [ ] **sha256 不匹配 → 拒绝启用并留痕**（篡改检测 fail-closed）
- [ ] 多版本并存与回滚可用（复用既有 `model_switch`，纪律零改动）
- [ ] 非白名单源须显式开启且留痕
- [ ] 权重版本与代码版本松耦合（回挂旧版代码可用，有测试）
- [ ] 仓库内**只**含权重清单 / sha256 / 模型卡，**不含权重本体**（体量断言）
- [ ] `npm test` 全绿

### 风险与前置假设

> ⚠️ **供应链安全是本章的红线**。权重是二进制制品，一旦被替换或投毒，判定行为会被静默改变——因此**来源白名单 + sha256 强校验 + 不匹配拒绝启用 + 留痕**四项缺一不可，且**不可配置为「校验失败仅告警」**。
>
> ⚠️ **本版仍不得宣称「判定准确率」**。准确率证据链（四层性能标准 + 第四方对照）属 v1.9.1——本版只宣称「形态成立」，不宣称「能力水平」。两者混说会让证据链失去意义。
