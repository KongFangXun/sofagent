## 与 Palantir 对标（差异化）

| Palantir 做法 | sofagent 做法 | 差异化 |
|------|------|------|
| Action Types 内嵌本体，LLM 调用必经 | A15 约束验证（事后）+ fde.md Policy（事前声明） | 事后审计 + 逐步前移 |
| OAG 五层确定性架构 | Harness 约束底座 + MCP + FORGE 双 Agent | 同构轻量，无需五层就位 |
| 集中式 Ontology OS，重度物化索引 | 分布式 knowledge/，联邦查询按需获取 | MIT 开源、零锁定、数据主权本地 |
| Markings + CBAC 本体级安全 | sensitivity frontmatter + 跨设备联邦过滤 | 渐进式演进 |

## 边界

- 不依赖 v1.3.0 运行时审计（本体不依赖审计）；两者并行推进。
- 分布式路线：不建中央本体操作系统，每个 Agent 自建本体（Ledger-Views-Policy），联邦查询跨设备共享，git diff + audit history 做硬证据链。
- 原 ROADMAP 中 v1.3.0 规划的 Ontology 内容（含 GB/T 48000.3-2026 国标对齐、控制图多循环 DAG 波次并行）整体顺延至本版本。
