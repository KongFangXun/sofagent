## 定位

v1.3.4 实现 **L3 组织能力市场**——Skill / Agent / 流程在企业内**发布 → 发现 → 调用 → 评价**，高频高价值的能力自然胜出。这是"有身份 Agent 的协作成果"的变现层：L2 让 Agent 能协作，L3 让协作成果可复用、可交易（组织内的能力市场）。

## P0：发布与发现

- **发布**：Skill / Agent / 流程打包为可发布单元（`market/` 目录 + 元数据 frontmatter）
- **发现**：按能力标签 / 使用频率 / 评分检索，复用 search_knowledge 检索链路
- **目录**：`market/index.md` 能力目录（自动生成，daemon @daily）

| 文件 | 改动 | 说明 |

| `engine/orchestrator/src/market/publisher.ts` | 新建 | 能力发布（校验元数据完整性） |

| `engine/mcp/src/tools/market-publish.ts` | 新建 | MCP `market_publish` tool |
| `engine/mcp/src/tools/market-search.ts` | 新建 | MCP `market_search` tool |

## P1：调用与评价

- **调用**：发现能力 → 一键挂载到 Agent（复用 registry 注册机制）
- **评价**：每次调用后记录结果（成功/失败/耗时/效果），累积评分
- **自然选择**：高频高价值能力置顶（评分 × 调用量加权），低价值能力沉底
- **审计**：市场调用走审计引擎（谁调了谁的能力、结果如何）

| 文件 | 改动 | 说明 |
|------|------|------|
| `engine/orchestrator/src/market/invoker.ts` | 新建 | 能力调用 + 结果记录 |
| `engine/orchestrator/src/market/rating.ts` | 新建 | 评分聚合（评分 × 调用量加权排序） |
| `engine/mcp/src/tools/market-invoke.ts` | 新建 | MCP `market_invoke` tool |
| `engine/mcp/src/tools/market-rate.ts` | 新建 | MCP `market_rate` tool |

## 验收标准

- [ ] 一个 Skill 可发布 → 其他 Agent 搜索到 → 挂载调用 → 评价回流
- [ ] 高频高价值能力在目录中自然上浮（评分 × 调用量加权）
- [ ] 市场调用全程审计（谁调了谁、结果如何，叠加身份）
- [ ] 4 个 MCP tool（publish/search/invoke/rate）可用
