## 定位

v1.3.3 实现 **L2 团队协作协议**——让多个有身份的 Agent 从"各自为战"变成"一个团队"。这是 ROADMAP「完整多设备协同」的核心：从单人约束到团队协作。

> 🧠 **A2A 协议参考**：Google A2A 为多 Agent 协作定义三层——动态服务发现 / 能力契约对齐 / 全状态接力。MCP 解决「脑和手」，A2A 解决「脑和脑」。本版本落地 A2A 思想，但不照搬协议（保持 MIT 开源 + 开放格式）。

## P0：五大机制

| 机制 | 做什么 | 关键设计 |
|------|--------|---------|
| **共享态** | 团队成员共享一个工作状态视图 | 复用 v1.1.8 automerge CRDT（clone-fork 共享版本史收敛） |
| **意图广播** | Agent 广播"我要做什么"，其他成员可见 | 事件总线：意图事件 → 订阅者接收 |
| **触发反应** | Agent 广播意图后，相关成员自动触发反应 | 意图 → 匹配订阅 → 触发子任务 |
| **冲突消解** | 多个 Agent 想改同一目标时按规则裁决 | trust 优先 + 时间戳 + 显式优先级 |
| **反馈放大** | 一次纠正/确认回流为团队学习信号 | 复用 think.md + Dream Cycle，团队级聚合 |

## P1：团队状态管理

- **团队定义**：`team.yml`（成员列表 + 共享态 schema + 广播频道）
- **团队会话**：成员 Agent 加入/退出团队，状态持久化（data/ 下按 team 隔离）
- **团队审计**：团队级审计轨迹（谁的意图 → 谁响应 → 结果如何），叠加 v1.3.1 身份

## 验收标准

- [ ] 两个 Agent 组队后，A 广播意图 → B 收到并触发反应
- [ ] 同时改同一文件时触发冲突消解（trust 高者胜，记录审计）
- [ ] 一次人工纠正 → 团队级 think.md 沉淀（反馈放大）
- [ ] 团队会话重启后状态不丢（CRDT 合并恢复）
