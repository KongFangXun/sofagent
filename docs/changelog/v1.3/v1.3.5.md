## 三、P1：instinct→skill 自动进化（ECC continuous-learning-v2 启发）

Dream Cycle（think.md + knowledge/）差最后一步——经验沉淀为文档后没有自动聚合成可复用 skill。

- **instinct 提取器**：从 think.md + decision-log + 审计 PASS/FAIL 自动提取「反复出现的判断模式」
- **置信度评分**：出现次数 × 通过率，≥0.7 才注入下次 context
- **`/evolve` 聚合器**：相关 instinct 聚合成正式 skill 写入**运行时 skill 目录** `~/.sofagent/skill/custom/`（走正常加载链，不另起一套；🔴 不是仓库的 `SKILL/` 发布源——那是 npm/ClawHub 发行版，Agent 自动写入 = 污染发布源）
- **evolver 输出格式带 DSH 插件形态预留**（2026-08-15 补充）：聚合产物除 SKILL.md 外同时落一份 `apply(ctx)` 包装（ctx.tools.register 注册为 DSH 可调用工具）——sofagent 进化出的每个能力自动成为 DSH 生态可分发插件；Cordis「Plugin 稳定身份 + Package 不可变版本」模型即 skill 版本管理的语义。**本版只落输出格式与目录约定，DSH 侧验证等 v1.3.6 后端接入后做**
- **错题本**：审计 FAIL + Refine 修复失败写独立 failure-log（负样本单独加权）

- **🔧 运维闭环**：`snapshot_list` / `snapshot_restore` 两个 MCP tool——审计快照时间线查询 + 恢复（强制人审）
