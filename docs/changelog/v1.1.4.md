# v1.1.4 开发日志 — 条件路由 + USB federation

> 状态：规划中 · 孔放勋 · 2026-07-15
> 前置依赖：v1.1.3（StateGraph + HITL 已就绪）

## 背景

v1.1.3 的流转是线性的——all PASS 走到 human。但真实开发中 audit 可能 FAIL（提交违规需要工程师修复）。v1.1.4 加条件路由：根据审计结果自动决定下一步是 push、fix 还是 ask。

## 交付一：条件路由（P0）

LangGraph conditional routing 替代硬编码的 PASS→push：

```
audit result:
  PASS  → 自动 git push → reviewer → human
  WARN  → reviewer → human（附带 WARN 标注）
  FAIL  → 回到 engineer fix → 重新 audit（最多 3 轮）
```

- **PASS**：代码无违规，自动进入下一节点
- **WARN**：有低风险提醒，标记在审查报告中给人看
- **FAIL**：阻断，强制回 engineer，修复后重新审计
- **FAIL 三次仍未过** → 人类介入，标记任务为 blocked

## 交付二：USB 检测 + federation.json（P1）

daemon 检测 `SOFAGENT` 标签的 USB 存储设备 → 自动读取 `federation.json` → 写入 `~/.sofagent/` → 重启 daemon。无头设备零交互入网。

CLI：`sofa-federation export-usb` 将配置写入 U 盘。

## LUI 感知

用户通过 Agent 对话感知：「我说一句'帮我做一个财务审计的 U 盘'，插上空盘就自动写好，标签已打、联邦密钥已注入。插到目标设备即可自动入网。」
