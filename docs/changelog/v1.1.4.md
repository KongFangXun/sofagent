# v1.1.4 开发日志 — LOOP 工具执行 + 条件路由

> 状态：规划中 · 孔放勋 · 2026-07-15
> 前置依赖：v1.1.3（StateGraph + HITL 已就绪，但 engineer/reviewer 节点走 composer 零工具路径，只能说话不能干活）

## 背景

v1.1.3 的 LOOP 有一个结构性缺口：engineer 和 reviewer 的默认实现走 `spawnSubAgent → composeWithDeepAgents → createDeepAgent({ tools: [] })`——DeepAgent 带着零工具上线，只能输出文字建议，**不能真的读写文件、跑测试、改代码**。v1.1.4 的核心任务：给这两个节点装上手脚，让 LOOP 从"会说话的规划引擎"变成"能干活的开发引擎"。

## 交付一：LOOP 工具注入（P0）——路 A

engineer 和 reviewer 节点不再走 composer 的零工具路径，而是直接调用 `createDeepAgent` 并注入 sofagent 自有的工具集。

### 新增文件：`orchestrator/src/tools.ts`

定义 6 个工具，每个工具内嵌 A1-A19 约束：

| Tool | 对应能力 | 内置约束 |
|------|------|------|
| `read_file` | Read | A7 先读再改 |
| `write_file` | Write | A1 不碰敏感 · A3 不改越界 · A16 非授权文件 |
| `edit_file` | Edit | 同上 |
| `run_bash` | Bash | A6 不坏构建 · A11 不滥资源 |
| `search_code` | Glob / Grep | — |
| `run_test` | npm test | A8 不逃验证 |

### 修改文件：`orchestrator/src/graph/nodes.ts`

- `defaultRunEngineer`：不再调 `spawnSubAgent`，直接 `createDeepAgent({ tools: [read, write, edit, bash, search, test], systemPrompt: buildConstrainedSystemPrompt(ENGINEER_AGENT), maxTurns: 20 })`
- `defaultRunReviewer`：同上，注入审查专用工具子集 + REVIEWER_AGENT

### 设计原则

- **tools 的 description 就是约束**——每个 tool 的 schema description 写清楚"什么能做、什么不能做"，模型读到 description 后自然遵守
- **约束底座完整性**：tool 执行前不额外做 hook 拦截（hook 留给 git commit 时触发），但在 prompt 中注入完整的 A1-A19 规则（通过 `buildConstrainedSystemPrompt` 的四层加载链）
- **兜底**：如果 `deepagents` 不可用或模型 API 不可达，优雅降级为旧路径（走 composer），在报告注明

## 交付二：条件路由升级（P1）

v1.1.3 已有 FAIL→engineer 回环路由，v1.1.4 补齐两个缺口：

- **PASS → reviewer**：审计通过后自动进入审查节点（v1.1.3 已有，验证稳定即可）
- **WARN → human_confirm 标注**：审查报告中附带 WARN 标注，不阻断自动流转
- **blocked 终态接入 audit history**：blocked 时写入 history.jsonl，可追溯

## 端到端验证（P0）

用一个真实任务跑通 LOOP 闭环：

> 任务：「在 `SECURITY.md` 第 5 行后加一条 HTML 注释 `<!-- v1.1.4 LOOP 验证 -->`」

验证点：
- [ ] engineer 节点能自己 Read SECURITY.md → Edit 加注释 → 产出 diff
- [ ] audit 节点检测到 diff → 跑 A1-A19 规则 → 判定 PASS（注释不含敏感内容）
- [ ] reviewer 节点审查变更 → 确认最小变更 → IS_PASS: YES
- [ ] HITL 节点弹出审查报告 → 等 y 确认 → END
- [ ] 如果人为在注释里加 `API_KEY=sk-...` → A2 FAIL → 回 engineer 修复 → 重新 audit → 最多 3 轮 → blocked
