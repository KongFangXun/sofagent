## 背景

v0.99.5（CI 自动化 + 审查修复版）于 07-04 发布。发布后执行全方面审查（15 维度），发现核心问题：**OIDC 自动化发布链路在 @sofagent/mcp 上断裂**——audit 包成功发布到 npm v0.99.5，但 mcp 包仍停留在 npm v0.99.4，且无 README。同时发现 25 项文档一致性、发布质量、CI 配置方面的问题。

## 修复清单

### P0（4 项）

#### P0-1：release.yml 去掉 mcp 对 audit 的 needs 依赖

- **问题**：release.yml publish-mcp job 依赖 publish-audit 成功（`needs: publish-audit`），audit 任何失败都会阻塞 mcp 发布，即使 mcp 代码完全没问题
- **修复**：去掉 `needs: publish-audit`，两个包独立发布
- **文件**：`.github/workflows/release.yml`

#### P0-2：创建 @sofagent/mcp README.md

- **问题**：npm 显示 "This package does not have a README."，mcp/package.json files 字段引用了不存在的 README.md
- **修复**：新建 `sofagent/mcp/README.md`，包含：一句话定位 + 安装 + 用法 + tools 表格 + 主仓库链接
- **文件**：`sofagent/mcp/README.md`（新建）

#### P0-3：mcp package.json files 字段 + .npmignore 对齐 audit

- **问题**：mcp .npmignore 用 `**/*.js.map`，audit 用 `dist/*.js.map`；mcp package.json files 字段无排除模式（audit 有 `"!dist/**/*.js.map"` 双重保险）。mcp 依赖 prepublishOnly 清理，脆弱
- **修复**：mcp package.json files 字段加入 `"!dist/**/*.js.map"` + `"!dist/**/*.d.ts.map"` + `"!dist/**/*.test.*"`；.npmignore 对齐 audit 模式（`dist/*.js.map`）。保留 prepublishOnly 作为三重保险
- **文件**：`sofagent/mcp/package.json` + `sofagent/mcp/.npmignore`

#### P0-4：evidence 目录残留「零运行时依赖」

- **问题**：`docs/evidence/cases/v099-release-test-2026-07-01/README.md` 第 37 行和第 94 行仍写"零运行时依赖 ✅ 属实"
- **修复**：改为「最小运行时依赖（仅 js-yaml）」
- **文件**：`docs/evidence/cases/v099-release-test-2026-07-01/README.md`
