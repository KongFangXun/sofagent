## 新增能力

### LLM 阅读理解防御性优化

两份独立 LLM 审查都出现了同一个误读（看到 `daemon | ❌ 移除` 就认为 daemon 被废弃）。本轮修复建立了 LLM 防御性写作原则：

- 表格中的否定标注（`❌ 移除`）必须附带明确的宾语说明
- 同一概念在多处使用不同词汇时，加术语对照表
- 旧术语在 CHANGELOG 中也全部统一，不给 LLM 推理空间
