## 用户反馈

> 「如果你是一个只有 3-5 人的小团队，面对复杂的行业 SaaS 开发，sofagent 的 FDE 流程能帮你在一两个小时内看清团队所有工作流节点，找出哪些该交给 AI、哪些该留给人做，并且直接变成每天在跑的自动化——不是画饼，是真能跑通。」

**遇到的改进需求**：
1. PowerShell 环境 curl 别名冲突（需 curl.exe 或 Invoke-RestMethod）
2. DingTalk Webhook 中文推送乱码（需 UTF-8 编码处理）
3. `.sofagent-data-path` 指向路径与实际路径不一致
