# FDE 阶段 4 · 交付（§7-§9）

## 本阶段目标

为每个 🔄/⚡ 节点生成三层实体（文档层 + Skill 层 + 运行层），引导部署，完成交付确认。达成后进入离场。

## 前置检查

如果你不是在 [出方案 / 部署 / 做三层实体 / 交付确认]，回到主 SKILL.md 重新判断阶段。本阶段前必须已完成 §6 量化判定。

## 执行步骤

### §7 交付方案（三层实体）

1. 对每个 🔄/⚡ 节点生成三层实体：

| 层 | 是什么 | 模板 |
|----|--------|------|
| 📄 文档层 | 节点详细说明（人读 + 编排引擎读） | `FDE/templates/nodes/node-template.md` |
| 🧠 Skill 层 | Agent 行为指令（节点的大脑） | `FDE/templates/skills/skill-template/SKILL.md` |
| 🔴 运行层 | 真实环境配置 | 写进部署清单 |

2. **黄金顺序（铁律）**：先运行层（跑通真实任务）→ Skill 层（抽象为模板）→ 文档层（补人读文档）。禁止直接写 Skill
   - **spec 引用要求（spec-first）**：动代码前先声明本变更对应的 spec（`spec: <workflow/fde/task 路径>`）；transcript 直出的口头需求须先沉淀为 fde.md / task 书再动代码——commit message 携带 `spec:` 标记或 `no-spec: <理由>` 显式豁免（`tools/check/check-spec-first.mjs` 定期扫描覆盖率）
3. 产出：「节点→方案对照表」+ 每个节点三层实体

### §8 部署引导

4. 引导用户在目标设备安装 sofagent 底座（`bash install.sh`）
5. 逐节点上线：🔄 创建 SubAgent session 跑通一次；⚡ 配置 AI 领航员确认岗位人员会用
6. 企业 Skill 注入：每个节点创建专属 Skill，注入行业术语 / 业务规则 / 历史案例
7. 检查点配置：每个 🔄/⚡ 输出端设检查点，默认抽检 10%。不合格 → 标记任务 → 反馈主人 → 记录异常
8. 教会一个人：每个 AI 节点指定企业方主人，退出信号为连续两天无人问「怎么用」

> ⚠️ 部署前先确认「客户就绪三前提」：流程已标准化（合同怎么审、风险怎么分级）、数据已打通（ERP/MES/财务不是孤岛）、权限边界已划定（高敏感场景明确自动化范围 + 人工确认节点）。三前提缺一，先补流程再上 Agent。

### §9 交付确认

9. 产出交付手册（4 章）：企业画像 + 部署方案 + 运行规范 + 维护指南
10. 每个节点三层实体打勾确认
11. 确认私有化评估体系：eval.md 有初始基线（≥5 条评分）、Skill 迭代历史可见、知识库演变可追溯
12. 调 `run_audit`（diff: "HEAD~1..HEAD"）跑审计 → 展示结果（见下方铁律）→ 调 `write_think` 记录交付质量

## 审计结果展示铁律（CRITICAL）

> 每次调用 `run_audit` / `audit_file` / `audit_data_change` 后，你**必须**：

1. **必须展示**：向用户展示审计结果摘要。**如果你执行了审计但不展示结果，等于没审计。**
2. **保留品牌**：展示时必须包含 `[sofagent]` 前缀。
3. **结构化展示**（不要用自己的话改写）：
   - **PASS**：✅ **[sofagent] 审计通过** · {N} 项检查 · {M} 条规则
   - **WARN**：⚠️ **[sofagent] 审计有警告** · {N} 项警告 · {逐条列出}
   - **FAIL**：❌ **[sofagent] 审计拦截** · {N} 项违规 · {逐条列出} · 修复指引
4. **关联反思**：`get_think` 查相关历史教训，展示"上次类似问题的教训"
5. **引导修复**：FAIL 时必须引导修复，不得跳过
6. **可验证证据**：交付物中声称"已审计"时，必须附 commit hash + `sofagent-audit --verify-commit <hash>` 验证指引——让用户能独立验证，而非信任 Agent 自报

## MCP 工具调用指引

- 交付后审计：`run_audit`（diff: "HEAD~1..HEAD"）→ 按上方铁律展示

- 反思沉淀：`write_think`（记录交付质量 + 教训）

> 未连接 MCP Server：

- 人工按部署清单逐项确认，交付手册落盘到企业名目录，审计由 `sofagent-audit` CLI 执行
