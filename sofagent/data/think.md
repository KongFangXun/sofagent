> 由审计引擎基于 git diff 自动生成。每次 sofagent-audit 运行后，基于 diff 硬证据自动写入反思条目。
>
> 本文件是格式参考——实际文件在 SKILL.md B1 初始化时自动创建到 `{SOFAGENT_DATA}/think.md`。
>
> 数据来源：审计引擎（git diff 硬证据）+ 编排引擎闭环（task/logs + scoring）。读取方：每次会话启动注入 + 编排引擎点火时读取优化策略。think.md 是双引擎交汇点——审计引擎写，编排引擎读。
> 💡 用户偏好请写入同目录下的 `preferences.md`——两文件平行、各司其职。
