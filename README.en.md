## What is this?

FDE deployment base — for SMBs and one-person companies. Deployment experts use standardized workflows to set up AI nodes on idle devices, with audit engine + orchestration engine hosting after implementation.

> **The 90/10 rule**: Don't compete with AI models on the 90% they already do well (code generation). The real value is in the 10% nobody dares skip — verification, audit trails, accountability. sofagent owns that 10%.

| Component | How it works |
|------|------|
| **Skill** (judgment) | Markdown files as rulebooks — 3-layer loading chain, complexity estimation, reflection loop |
| **Scripts** (execution) | Bash scripts for mechanical work. Agent invokes via shell (falls back to Read/Edit tools on non-bash platforms) |
| **Platform safety net** | Loading chain + circuit breaker + loop detection — enforced by OpenClaw hooks |

> sofagent is a constraint layer — it works when the agent reads and chooses to comply. It is not hard-coded enforcement.

## How it works

```
3-layer loading chain (constitution → reflection → your rules)
          ↓
    A0 complexity estimation
    ├── 🟢🟡 Simple → quick response
    └── 🔴 Complex → orchestration engine fires up
                   │
              Smart decomposition → Loop checks → Reflection ★
                   ↓
          next task learns from the last
```

| Layer | What it does |
|------|------|
| **Foundation** | 3-layer loading chain — constitution (4 hard rules + 6 principles) → reflection zone → your rules |
| **Engine** | Task orchestration — fires for 🔴 complex tasks: smart decomposition + Loop checks + reflection |
| **Evolution** | Progressive thinning — repeat tasks get lighter orchestration. If it breaks, restore full |

> 💰 Cost: ~3,000 foundation tokens always-on (2.5% of 128K). Orchestration adds ~800 tokens for complex tasks.
> ⚠️ **Known limitations**: No third-party usage data; reflection is LLM self-assessment; data stored in plaintext; not a multi-user system. Full list in [LIMITATIONS.md](./LIMITATIONS.md#known-limits).

## Platform capabilities

| Platform | Loading chain | Orchestration | Automation |
|------|------|------|------|
| OpenClaw | Hook injection (all layers) | `ao compose` fully available | High |
| WorkBuddy | Layer 1 via @skill, L2/3 agent-cooperative | `ao compose` available | Medium |
| Codex / Hermes / Claude Code | Layer 1 via seed instruction, L2/3 cooperative | Unavailable | Low |

> Non-OpenClaw: orchestration / Hook / circuit breaker are OpenClaw-only. Other platforms get constitution layer only. See [LIMITATIONS.md](./LIMITATIONS.md#平台依赖).

## Does it actually work?

> **v0.92 OpenClaw control experiment**: same model, independent sessions. Sofagent: 0% variable over-modification. Bare agent: 100% over-modification. Discipline +2. [Full report](./docs/evidence/benchmark/2026-06-25-openclaw-task1-control.md). See [evidence.md](./docs/evidence/evidence.md) for community data.

- ❌ Not an AI framework — doesn't manage model APIs
- ❌ Not a skills marketplace — doesn't maintain reusable skills
- ✅ FDE base + audit engine — telling agents what they can do, can't do, and when to stop

## Quick Start

```bash
git clone https://github.com/KongFangXun/sofagent.git
cd sofagent && bash sofagent/scripts/install.sh
```

| Platform | Command |
|------|------|
| **OpenClaw** | `bash sofagent/scripts/install.sh` (auto-detected) |
| **WorkBuddy** | `bash sofagent/scripts/install.sh --platform workbuddy` |
| **Claude Code** | `bash sofagent/scripts/install.sh --platform claude` |
| **Codex** | `bash sofagent/scripts/install.sh --platform codex` |
| **Hermes Agent** | `bash sofagent/scripts/install.sh --platform hermes` |

### Verify

```bash
bash sofagent/scripts/verify.sh    # via install.sh
# or via npm
sofagent-verify                     # after npm install -g @sofagent/audit
```

> Expected: all 50 checks pass. Add `--json` for CI/CD.

### First task

Open your agent client. Try a task that needs multi-step decomposition:

```
/goal Analyze the code quality of this project and generate an improvement recommendations report
```

Check results:
```bash
ls .sofagent/task/logs/        # execution logs
cat .sofagent/think.md         # auto-generated reflection
```

**Got it working?** [HANDBOOK.md](./HANDBOOK.md) teaches tuning, [DEVELOPMENT.md](./DEVELOPMENT.md) explains internals, [ARCHITECTURE.md](./ARCHITECTURE.md) covers design rationale.
