## What is this?

Open-source FDE toolkit for SMBs and one-person companies — harness base governs agent behavior, audit engine watches code changes. DIY: map your workflows, deploy AI nodes, all on your own.

> **The 90/10 rule**: Don't compete with AI models on the 90% they already do well (code generation). The real value is in the 10% nobody dares skip — verification, audit trails, accountability. sofagent owns that 10%.

> **Maturity**: sofagent is something we've been running in our own companies (investment / tech / e-commerce) for about a month, now open sourced. The audit engine (sofagent-audit) is stable in daily use, with 406 automated tests all passing. The orchestration engine and FDE deployment workflow work for us, but aren't polished to "install and go" yet. If you try it, we'd love to hear what you're using it for and what breaks.

| Component | How it works |
|------|------|
| **Skill** (judgment) | Markdown files as rulebooks — 3-layer loading chain, complexity estimation, reflection loop |
| **Scripts** (execution) | Bash scripts for mechanical work. Agent invokes via shell (falls back to Read/Edit tools on non-bash platforms) |
| **Platform safety net** | Loading chain + circuit breaker + loop detection — enforced by OpenClaw hooks |

> sofagent is a constraint layer — it works when the agent reads and chooses to comply. It is not hard-coded enforcement.

### Two-layer architecture

sofagent has two layers — the audit layer is platform-independent, the orchestration layer runs on OpenClaw:

| Layer | What it does | Dependencies |
|------|------|------|
| **Audit layer** (sofagent-audit) | Audits agent-written code — git diff as hard evidence, 11 rules, pre-commit hook gate | If your code is in a git repo, it works. Agent-agnostic, platform-agnostic |
| **Orchestration layer** | Runs FDE-deployed workflow AI nodes — auto task decomposition, reflection recording, think.md management | OpenClaw (FDE toolkit, not your daily agent) |

OpenClaw is not something you "use" — it runs on the device, handling FDE workflow nodes in the background. You and your team use whatever agent you like to write and commit code. sofagent-audit audits all agent output via pre-commit hooks — regardless of who wrote it.

> Full explanation of the two usage modes: [LIMITATIONS.md §Platform Dependencies](./LIMITATIONS.md#平台依赖).

## How it works

```
     Audit engine (every commit)               Orchestration engine (FDE onboarding + periodic)
            │                                           │
            ├─ git diff scan                            ├─ FDE onboarding: one-time workflow.yaml generation
            ├─ Rule checks A1-A11                       │       └─ Smart decomposition → orchestration plan
            │                                           │
            │                                           ├─ Production: AI nodes run per workflow
            │                                           │       ├─ 🔄 Auto-execute
            │                                           │       └─ ⚡ AI navigator assist
            │                                           │
            │                                           ├─ Periodic A/B re-test (every N sessions)
            │                                           │       ├─ Re-orchestrate a new candidate
            │                                           │       └─ sofagent-orchestrate-compare
            │                                           │              ├─ Candidate wins → promote
            │                                           │              └─ Current better → keep
            │                                           │
            └────────────── think.md ───────────────────────┘
                 (audit writes / orchestration reads / A/B results → orchestrator/)
```

| Engine | What it does | Agent cooperation | Trigger |
|------|------|:--:|------|
| **Audit engine** | git diff → rule checks → auto-generate think.md | ❌ | Every git commit |
| **Orchestration engine** | One-time workflow generation at FDE onboarding + periodic A/B re-optimization | ✅ | FDE deploy / scheduled |

## How sofagent audits your agents

sofagent-audit is an npm-installable TypeScript CLI. It scans git diffs, not agent logs.  
No agent cooperation needed. No OpenClaw needed.

```bash
npm install -g @sofagent/audit
sofagent-audit --diff HEAD~1..HEAD --task "your task description"
```

| Platform | Audit (git diff) | Orchestration (workflow nodes) |
|------|:--:|:--:|
| Any platform with git | ✅ pre-commit hook | — |
| OpenClaw | ✅ pre-commit hook | ✅ Hook + session isolation + circuit breaker |

> The table above describes which **capability layer** works where — not which **agents** are supported. The audit layer is agent-agnostic (it only looks at git diffs). The orchestration layer runs on OpenClaw only.

## Does it actually work?

> **v0.92 OpenClaw control experiment**: same model, independent sessions. Sofagent: 0% variable over-modification. Bare agent: 100% over-modification. Discipline +2. [Full report](./docs/evidence/benchmark/2026-06-25-openclaw-task1-control.md). See [evidence.md](./docs/evidence/evidence.md) for community data.

## What sofagent is not

- ❌ Not an AI framework — doesn't manage model APIs
- ❌ Not a skills marketplace — doesn't maintain reusable skills
- ✅ FDE toolkit: harness base + audit engine — telling agents what they can do, can't do, and when to stop

## Quick Start

```bash
git clone https://github.com/KongFangXun/sofagent.git
cd sofagent && bash sofagent/scripts/install.sh
```

| Platform | Command |
|------|------|
| **OpenClaw** | `bash sofagent/scripts/install.sh` (auto-detected) |
| **WorkBuddy** | `bash sofagent/scripts/install.sh --platform workbuddy` |
| **Claude Code** | `bash sofagent/scripts/install.sh --platform claude` |
| **Codex** | `bash sofagent/scripts/install.sh --platform codex` |
| **Hermes Agent** | `bash sofagent/scripts/install.sh --platform hermes` |

### Verify

```bash
bash sofagent/scripts/verify.sh    # via install.sh
# or via npm
sofagent-verify                     # after npm install -g @sofagent/audit
```

> Expected: all 50 checks pass. Add `--json` for CI/CD.

### First task

Open your agent client. Try a task that needs multi-step decomposition:

```
/goal Analyze the code quality of this project and generate an improvement recommendations report
```

Check results:
```bash
ls .sofagent/task/logs/        # execution logs
cat .sofagent/think.md         # auto-generated reflection
```

**Got it working?** [HANDBOOK.md](./HANDBOOK.md) teaches tuning, [DEVELOPMENT.md](./DEVELOPMENT.md) explains internals, [ARCHITECTURE.md](./ARCHITECTURE.md) covers design rationale.
