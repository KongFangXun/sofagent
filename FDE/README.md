# FDE Agent · 企业 AI 治理诊断框架

## 一句话

sofagent FDE（Forward Deployed Engineer）帮你的企业梳理 AI 该在哪些岗位干、怎么干、干了之后怎么审计——从"AI 很强"到"AI 在替我干活且干得对"。

## 解决什么问题

很多企业上 AI 的路径是反的：先选模型、搭平台、买 Agent，结果发现没人用。问题不在技术，在于**企业还没搞清楚自己的业务流程，就想让 AI 来接管**。

FDE 把这件事倒过来：先逐岗位梳理工作流，用五要素（输入/输出/负责人/耗时/痛点）把每个环节摸清；再用三问判定法识别哪些环节适合上 AI（🔄 自动执行 / ⚡ 强化岗位 / 👤 暂不动），算清每个节点的年节省金额；最后交付三层实体（文档层 + Skill 层 + 运行层），让 AI 节点真的跑起来。

部署完不等于结束。每个 AI 节点带审计引擎（每次变更自动审计）+ 反思库（think.md 沉淀经验）+ 数据主权边界（企业数据不外传）。人离场后，FDE Agent 留下继续跑——巡检、审计、优化，7×24 在线。

## 两条上手路径

FDE 支持两种使用方式——根据你的需求选择：

### 路径 A · 方法论路径（零依赖，不需要 Node.js）

如果你只想了解 FDE 方法论、手动梳理工作流：

1. **阅读**：[GUIDE.md](./GUIDE.md)——完整方法论手册（半天精读，读完能独立做 FDE）
2. **操作**：用你喜欢的工具（Excel + 人脑也能跑）按手册逐步梳理
3. **产出**：企业画像、节点方案、部署清单

> 💡 方法论本身不依赖任何工具——五要素 + 三问判定法纯对话/纸笔即可完成。

### 路径 B · 工具路径（需 Node.js ≥ 18）

如果你想用 sofagent 工具链辅助（自动审计 + 知识沉淀 + Dashboard）：

1. **安装**：`npm install -g @sofagent/audit && sofagent-audit --init`
2. **连接**：在你的 AI Agent 平台加载 FDE Skill（WorkBuddy 搜 `sofagent`，或 `bash install.sh`）
3. **对话**：跟 Agent 说"帮我做 FDE 诊断"，它会从 §1 进场开始引导你

> 💡 不想安装？先看 [GUIDE.md](./GUIDE.md) 了解方法论，再用你喜欢的 AI 平台手动操作——FDE 方法论本身不依赖工具，Excel + 人脑也能跑。

## 效果对比

| | 没有 FDE | 有 FDE |
|--|---------|--------|
| AI 在干什么 | 每次任务从零开始 | 按岗位 SOP 执行，节点有明确边界 |
| 该上哪些 AI | 凭感觉拍脑袋 | 五要素 + 三问判定，按 ROI 排出优先级 |
| 审计 | 没有 | 每次变更自动审计，责任到人 |
| 经验沉淀 | 全靠人记 | 自动写 think.md，节点越跑越聪明 |
| 数据安全 | 说不清数据去哪了 | 数据主权审计，企业数据不外传 |
