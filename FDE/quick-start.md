# 5 分钟快速上手 · FDE Agent 能帮你干什么

> 你不需要懂代码。这篇文章用大白话告诉你：装了这个 skill，你的工作会发生什么变化。

---

## 一句话

FDE Agent 帮你把"企业该怎么用 AI"从模糊的感觉变成可交付的方案。

## 装之前 vs 装之后

| 场景 | 没装 FDE Agent | 装了 FDE Agent |
|------|------|------|
| 老板问"我们该上哪些 AI" | 凭感觉拍脑袋 | 逐岗位梳理工作流，按 ROI 排出优先级 |
| AI 上了之后跑偏 | 不知道哪出问题 | 三层实体定位——是 Skill 层约束不够还是运行层配置不对 |
| 同一个流程反复优化 | 每次从零开始 | 本体模型复用，加新节点只走一遍 §4-§7 |
| 要给老板交差 | PPT 现编 | 交付手册 4 章已落盘 |

## 你需要做什么

### 第 1 天：聊业务

跟 Agent 说"帮我做 FDE 部署"。Agent 会问你：

1. 公司叫什么？做什么？多少人？
2. 哪些岗位最忙、最累？
3. 日常用钉钉还是飞书？业务系统有哪些？

你正常聊天就行，**不聊 AI**——这一步只摸清底子。

### 第 3-5 天：看方案

Agent 拿出一份部署方案：
- 每个岗位的工作流节点图
- 哪些环节适合上 AI（🔄 自动执行 / ⚡ 强化岗位 / 👤 暂不动）
- 每个候选节点的年节省金额
- 按 ROI 排好的优先级清单

你看一眼觉得合理就行。

### 第 7-10 天：拿到交付物

Agent 产出一套文档：
- **企业画像**——你们公司的 AI 化全景图
- **节点方案**——每个 AI 节点的三层实体（文档层 + Skill 层 + 运行层）
- **部署清单**——哪些先上、怎么验收
- **交付手册**——背景/架构/操作手册/维护指南

你拿着文档自己决定怎么落地。

### 持续：有事再找

| 什么时候 | 找 Agent 干什么 |
|------|------|
| AI 节点跑偏了 | 描述问题 → 定位是哪层 → 改对应文档 |
| 要加新节点 | 从 §4 走一遍，复用已有本体模型 |
| 要评估效果 | 复跑量化公式，对比实际 vs 预期 |

## 不用操心的事

- **不需要写代码**——Agent 产出的是 Markdown 文档，不是代码
- **不需要装引擎**——skill 自带全部能力，装了就用
- **不需要懂 AI 技术**——Agent 会用大白话跟你聊业务
