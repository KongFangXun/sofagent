# 三单匹配规则 Skill

## 触发条件

当需要比对采购订单、入库单和发票的数据一致性时触发。

## 匹配规则

1. **供应商名称**：三单的供应商名称必须完全一致
2. **数量**：发票数量 ≤ 入库单数量 ≤ 采购订单数量
3. **单价**：发票单价与采购订单单价的差异 ≤ 5%
4. **总金额**：发票总金额与入库单总金额的差异 ≤ 5%

## 异常处理

- 差异 > 5%：标记为异常，升级审批
- 差异 ≤ 5% 但 > 1%：WARN，记录但放行
- 差异 ≤ 1%：PASS，正常处理

## 适配

1. 调整差异阈值（5%/1%）
2. 添加额外的匹配规则（如税率、运费等）
