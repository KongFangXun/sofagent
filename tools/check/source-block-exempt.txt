# 来源块溯源存量台账（被 tools/check/doc-discipline.sh Face 3b 消费）
# ============================================================
# 语义：`> 📖 来源：` / `> 📐 来源：` 溯源块的**存量债**——缺链接、缺原文发布日。
#       纪律本体见 CONTRIBUTING.md「来源块溯源规范」（只写作品名 + 链接 + 原文发布日）。
#
# 判定口径（集合相等，与 knowledge-legacy-path-exempt.json 同族）：
#   实测逐文件计数 == 本台账逐文件计数。三者任一即红：
#     · 新增（某文件实测 > 台账）——债在涨，拦；
#     · 清理后未同步台账（实测 < 台账）——**这是设计使然**：清存量也是可见动作，
#       必须把台账一起改小，让 diff 记录"债减少"这件事本身；
#     · 台账条目对应文件已无债（实测为 0）——条目陈旧，删。
#
# 🔴 反作弊：本台账数字**只许随真实清理下调**。上调 = 债增加，必须在 diff 中可见
#    并由负责人裁决——「只调数字不清理」是假绿，与文档预算的
#    「只调警戒线不归并 = 不合格」（playbook/regression-checklist.md 头部）同罪。
#
# 格式：<类别>TAB<文件>TAB<计数>     类别 ∈ {缺链接, 缺日期}
#   用 .txt 而非 .json：本台账由 bash 门禁消费，而 macOS 不自带 jq，
#   走 .json 会引入解析依赖（.json 台账家族均配 .mjs 消费方，此处不适用）。
#
# 刷新方式：门禁报红时会直接打印「应为此内容」的台账正文，整段替换即可。
